# 0.4 변경 기록

0.4는 0.3과 같은 이야기·저장을 쓰고, 세계(배경 배치·시간·날씨·배경 그리기 방식)만 새로 만든 판이다.
주소: `moonforest-0.4.html`. 0.3(`moonforest-0.3.html`)은 그대로 두므로 되돌리려면 0.3 주소로 열면 된다.
코드에서는 `versionRoute.worldRevision==="0.4"`(html `data-world="0.4"`)로만 분기한다.

## 2026-11-18
- 0.4 진입 주소 추가(0.3 빌드에 함께 포함, 저장 공유).
- 시간과 날씨 1차: 하루 주기(게임 1시간 = 실제 1분, 09:00 시작, 기록별 저장), 새벽·낮·노을·밤 화면 색 변화, 하늘의 노을 띠·별·달, 날씨 전환(맑음·흐림·비·폭풍), 비(겹 2장), 번개 섬광, 미니맵 아래 시계·날씨 표시. 여관에서 쉬면 다음 날 07:00. 동굴은 영향 없음. 3D 프레임 비용 없음(화면 위 합성 레이어 + 기존 하늘 셰이더 유니폼 3개). 소리는 승인된 자료가 없어 미연결.
- 0.4 제목·탭 이름 표기.
- 먼 거리용 지오메트리(작은 배치물): 묶음 LOD가 거의 줄지 않아(풀 한 포기 1,397/1,397/1,329 삼각형) 평원 언덕 화면 삼각형의 41%가 먼 풀이었음. 불러올 때 메시에서 직접 두 단계(약 18%, 4%)를 만들어 화면 점유율 기준으로 추가(풀·바위·덤불·울타리·텃밭). 숨기거나 거리를 줄이지 않음.
- 평원 초원 풀(1차): 기존 풀 포기 모델을 이용해 초원 전체에 약 1만 2천 포기를 구역(20m) 단위 묶음(thin instance)으로 배치. 덩어리지게 자라고, 시냇가는 무성하고 키가 크며, 길가에서는 성기고, 길·야영지·물·절벽·바위 안에는 없음. 가까운 구역은 가벼운 모델(약 200 삼각형), 먼 구역은 아주 가벼운 모델(약 28)로 일부만 그림. 그림자·충돌·배치 기록 없음.
- 초원 풀 2차: 구역 30m(동시에 그리는 묶음 절반), 가까운 풀 84 삼각형/32m, 위치 계산을 구역별 근처 길·시내만 보도록 변경(전체 3.6초 → 0.04초). 시계 표시를 미니맵 왼쪽으로(휴대폰에서 물약 버튼과 겹침).
- 덤불 층(1차): 나무 수관 가장자리와 시냇가에 덤불을 묶음으로 배치(길·야영지 제외, 나무 셋 중 둘). 기존 덤불 모델 사용, 충돌 없음.
- 먼 거리용 모델 색 수정: 삼각형마다 텍스처 좌표를 하나만 써서(섬 사이 보간 제거) 줄인 덤불이 검게 보이던 문제 해결. 덤불 층의 가까운 구역은 원래 덤불 모델을 그대로 사용.
- 배경 선명도: 0.4는 나무·바위·덤불·울타리·집의 가까운 단계와 중간 단계를 더 먼 거리까지 유지(화면 점유율 기준 0.22/0.035 → 0.08/0.006, 거리로 약 1.7배/2.4배). 단계별 차이는 주로 텍스처 크기(나무 2048/1024/512, 바위·덤불 512/256)라서, 평원 길가 실측으로 보이는 배치물 105개 중 91개가 가장 낮은 단계였음. 삼각형 증가는 프레임당 약 5%. 0.3은 그대로.
- 초원 풀 층·덤불 층 끔(2026-11-18): 땅에 고르게 뿌린 풀포기와 어두운 덤불이 초원이 아니라 흩어진 쓰레기처럼 보인다는 평가. 평원은 원래 배치만 사용. 코드는 남겨 두되 `SCATTER_VEGETATION=false`. 식생은 고르게 뿌리는 방식이 아니라 손으로 구성한 군락 단위로 다시 설계할 것.
