# 달빛숲 v4.13 — 입력과 효과음 동기화 점검

v4.12의 음악·효과음·Critical 표시를 유지합니다. 실행 방법은 저장소 루트 README를 참고하세요.

## 발견한 문제와 수정

- 활 당기기 시작을 오디오 관리자의 다음 프레임 감지에 맡기던 부분을, 차징이 실제 승인된 이벤트에 직접 연결했습니다.
- 활 차징 중 조기 해제·피격·메뉴 열기에서 당기는 소리가 남거나, 메뉴를 닫을 때 다시 이어지던 문제를 수정했습니다.
- 위치 차징과 운석·화살비 시전 취소 시 준비 반복음을 즉시 정지합니다. 운석이 내려오기 시작한 뒤 취소하면 낙하음도 정지합니다.
- 전사의 타격과 운석 충돌로 레벨업 선택창이 열리는 경우, 공격음이 빠지지 않도록 피해 처리보다 먼저 재생합니다.
- 이미 발생한 짧은 효과음은 일시정지 시 낮은 음량으로 마무리합니다. 재개할 때 오래된 효과음을 뒤늦게 이어 재생하지 않습니다. 시전 반복음은 일시정지 동안 즉시 음소거합니다.
- 효과음 18개가 몰려도 플레이어 공격·회피·방어 피드백이 군중음보다 우선하도록 조정했습니다.
- 미습득 스킬 입력에도 실패 알림음을 연결했습니다. 반복 실패음 제한은 유지합니다.

## 검증 범위

| 입력/상황 | 확인 내용 |
| --- | --- |
| 전사 J·좌클릭 유지 | 횡베기 2회와 내려베기 1회의 실제 타격 시점에 각각 한 번 재생 |
| 궁수 좌클릭 | 누르기 → 차징 완료 알림 1회 → 유지 중 발사 없음 → 떼면 발사 1회 |
| 궁수 J 유지 | 연속 자동 발사마다 당기기·발사음 연결 |
| J·좌클릭 동시 입력 | 한쪽만 놓았을 때 중복 발사 없음 |
| 차징·시전 취소 | 짧게 놓기·피격·메뉴·이동·새 액션으로 취소 시 준비음 정지 |
| 위치 공격·스킬 | 약/강 에너지볼, 서리 3회, 운석 낙하/충돌, 회복 5회 |
| 전사·궁수 스킬 | 돌진·광역 베기·패링, 트리플샷·덫·화살비 |
| 세 직업 회피 | 구르기 및 뒤 행동별 소리, 거절된 반복 회피는 중복음 없음 |
| 이동 | 점프/착지 각각 1회, 실제 지상 이동에 발소리, 정지 시 발소리 없음 |
| 예외 상황 | 레벨업 순간 타격, 사망으로 중단된 공격, 효과음 채널 혼잡 |
| 기존 오디오 | BGM 전환, 설정 저장, 몬스터/보스, UI, 누락 파일·실행 오류 |

게임 실행 파일에서 실제 입력 처리 함수와 액션 상태를 구동하고 효과음 재생 횟수, 활성 AudioSource, 음량, 피해 발생을 함께 확인합니다. OS 키보드/마우스 장치를 직접 누르는 방식이나 사용자 스피커의 지연을 측정한 검증은 아닙니다.

12개 주요 동작 음원의 앞부분도 검사했습니다. 파일 안에서 피크의 5%에 도달하는 시점은 0.48~5.58ms로, 긴 선행 무음은 없습니다. 이 값은 전체 입력-스피커 지연을 뜻하지 않습니다.

수정 전 결과는 `Verification/before-audio-tests.json`, 수정 후 결과는 `Verification/audio-tests.json`에 있습니다. 일부 취소·연속 입력 사례를 추가했으므로 전후 총 검증 수는 다릅니다. 게임에 사용하는 음원은 `Assets/Resources/Audio`, 음원 제작 스크립트는 `Tools/Music`에 있습니다.

최종 결과: 검증 86개 통과, 실행 오류 0개. 빌드 오류 0개·경고 0개.
