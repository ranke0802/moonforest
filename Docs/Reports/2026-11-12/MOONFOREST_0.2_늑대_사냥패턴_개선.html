절반의 체력에서 몰아붙이는 늑대

기존 R8·R9 외형과 14개 동작을 유지하면서 행동 선택, 실제 도달 거리와 짧은 타격 구간을 보완했습니다.

HP 50% 초과 · 신중한 사냥

공격 한 번 → 마무리·반격 빈틈 → 1.35–1.65초 선회 → 다음 공격.

기본 패턴에서는 연속 입질을 제외합니다. 가까우면 입질·압박, 맞는 거리에서는 제압, 멀면 도약을 선택합니다.

HP 50% 이하 · 맹렬한 압박

적중하고 다음 동작의 실제 거리 안에 있을 때만 최대 3회까지 연결 → 마무리 → 0.55초 선회.

막힘·빗나감·거리 이탈·경직·넘어짐은 연결을 끊습니다. 체력 전환으로 재생 중인 공격이나 기상을 취소하지 않습니다.

도망 대신 공격 태세

발견 → 일어나기 → 관찰 → 접근·공격 → 마무리 → 원본 선회 보행 → 재공격
  • 멀리 등을 돌려 달아나 공격 거리를 만드는 후퇴를 제거했습니다. 가까운 거리에서 장거리 맞춤 패턴을 요청하면 그 차례에는 도달 가능한 근접 공격을 사용하며 저장된 순서는 유지합니다.
  • 선회는 Circle_Watch의 보행과 실제 루트를 함께 사용합니다. 전진 달리기를 옆으로 밀거나 루트만 좌우 반전하지 않습니다. 현재 원본 선회 방향을 유지하며 장애물이 막으면 멈추고 다음 행동으로 넘어갑니다.
  • 선회 경로 막힘, 시작보다 0.65m 넘는 거리 증가 또는 60도 넘는 시선 이탈을 제한합니다. 관찰·회복 중에는 0초 포즈를 유지해 제자리 걸음을 없앴습니다.

공격이 닿지 않던 원인과 조치

  1. 한 순간에만 검사하던 입·앞발 중심 판정을 짧은 소스 시간 구간으로 확장했습니다. 플레이어의 실제 캡슐 반경을 한 번 더하고, 구간에 맞춰 자른 이전·현재 상대 궤적을 검사합니다.
  2. 실제 앞발 압박·도약 도달 거리보다 멀리서 시작하던 조건을 수정했습니다. 압박 최대 2.80 → 2.70m, 도약 최대 26.20 → 25.80m입니다. 판정 구를 크게 만들어 대신 맞히지 않습니다.
  3. 입질은 입·머리, 압박은 해당 앞발만 타격합니다. 벽·회피·방패·공격 후 빈틈은 유지하고, 같은 공격은 회피되거나 맞은 뒤 다시 피해를 주지 않습니다.
  4. 준비 → 빠른 접촉 → 마무리 휘핑을 강화했습니다. 아래 배수는 접촉 구간의 소스 시간 진행률이며 전체 공격 속도나 피해 배수가 아닙니다. 공격 확정 뒤 추적 회전은 중지합니다.

14개 동작의 역할

휴식·발견·일어나기·주변 경계 / 걷기·달리기 / 입질·압박·도약·제압 / 피격·버티기·쓰러짐·기상. 연속 입질은 같은 입질을 독립된 공격으로 연결합니다. 조건이 없는 피격 동작을 억지로 재생하지 않습니다.

유지한 자원과 재사용 기준

  • 25,080삼각형, 28관절, 원본 12개 + R9 2개 동작, Breath 1개, 승인된 4K 텍스처와 기존 카툰·외곽선·내부선·LOD를 유지했습니다. 메시·UV·웨이트·바인드·TRS 키를 수정하지 않았습니다.
  • 추가 모델·텍스처·렌더 패스·개체별 타이머 없이 기존 루프와 공유 자원/개체별 포즈를 사용합니다. 접촉 이력은 개체당 고정된 4개 지점이며 공격 중에만 갱신합니다.
  • 프로젝트에 .agents/skills/moonforest-canine-unit를 포함하고 사용자 스킬로도 설치했습니다. AGENTS.md에서 연결합니다. 미래 개과 유닛은 이 기준으로 체형에 맞게 리타기팅·접지·판정을 검증해야 하며 기존 유닛 전체가 자동 교체되는 것은 아닙니다.

검증 범위

  • 최종 게임 회귀 검사 111개 통과. 네 맵에서 1·5·10·20마리 소환과 3회 재사용, 취소·재시도, 방어·회피·피격·넘어짐·사망·보상 및 원본 0.1 보존을 포함합니다.
  • 실제 시작 가능 거리 양 끝 × 30/60Hz × 0.5/1/2배: 48/48 접촉 통과. 선호 거리는 기존 공격 검사에서 함께 확인합니다.
  • 실제 모델과 게임 루프의 기본 AI 8조건 × 45초, 14개 동작 역할, 이동 표적 8조건, 같은 공격 중복 검사 18조건, 정지·회복 100프레임 무이동 및 막힌 선회 중지를 확인했습니다.
  • 개과 스킬 검사 도구 6개 통과, 등록 원본 해시와 설치 사본 일치를 확인했습니다.

위 검사는 Node/Babylon NullEngine의 CPU·판정·자원 수명 근거입니다. 실기기 FPS·GPU·발열·터치 조작감과 이번 빌드의 게임 화면 검수는 미측정입니다. 원본색 렌더·관절 확대 검수는 변경하지 않은 R9 제작 기록으로 보존합니다.
