작업 체크리스트

상태요청구현 내용과 남은 확인
구현표면 ± · NPC 삭제 · 상자 상태붙일 면을 ± 버튼으로 선택하고 추가 NPC 및 스토리 NPC를 삭제할 수 있습니다. 스토리 주민은 목록에서 복원할 수 있고 변경은 이 브라우저에 저장됩니다. 삭제한 주민과의 대화가 필요한 의뢰는 복원 전까지 진행이 막힐 수 있으나 기존 진행 기록은 보존됩니다. 상자 외형은 열림·닫힘·자동을 선택하며 이미 획득한 보상은 다시 지급되지 않습니다.
수정 · 실기기 미확인마을 숲 부근 순간이동출구 통로의 경계가 일반 이동 제한에 잘못 걸리는 불일치를 수정했습니다. 경계 반복 검사는 통과했으나, 제보된 모든 순간이동이 이 원인인지는 실제 플레이로 확인하지 못했습니다.
구현 · 공개 반영 확인짧은 게임 주소사이트 루트 MoonForest 게임에서 0.1 게임으로 연결합니다. 기존 직접 주소와 전달받은 옵션은 유지합니다. 공개 서버에서 새 진입 파일과 게임·편집기 파일의 해시를 확인했습니다.
구현이동 · 달리기 속도설정에서 각각 조절하고 저장합니다. 기본값은 기존 일반 속도와 달리기 1.8배입니다. 전투 판정과 공격 속도는 변경하지 않았습니다.
구현 · 실기기 미확인UI 위치 · 크기와 JSONHUD와 등록된 창을 이동·크기 조절하고, 숨겨진 창은 미리보기로 조절합니다. ‘창 미리보기에서 내부 요소 선택’을 체크하면 창 내부 항목도 선택할 수 있습니다. PC는 가장자리·모서리, 모바일은 두 손가락으로 크기를 조절합니다. JSON 다운로드·불러오기와 검수 JSON 기본값 적용을 지원합니다. 실제 모바일 제스처·화면 겹침은 확인하지 못했으며, 미리보기에 존재하지 않는 동적 항목은 해당 화면을 먼저 열어야 선택할 수 있습니다.
구현 · 시각 미확인산 · 구름 · 날씨 · 마을 전망산의 각진 능선과 면 색상을 완화하고 마을에서 대평원을 가리는 원경 배치를 조정했습니다. 기존 구름 텍스처를 이용해 흐름을 겹치고 맑음·흐림·안개를 선택할 수 있습니다. 동굴 날씨는 유지합니다. 구름 셰이더는 텍스처 조회가 하나 추가되므로 실제 GPU 부하와 자연스러움은 미측정입니다.
부분 구현맵 · 선택 오브젝트 폴리곤설정에서 등록된 배치와 지형의 확인 가능한 삼각형 합계를 요청할 수 있습니다. 집계 불가 에셋, 동적 배우·효과와 실제 LOD는 제외되므로 정확한 전체 수가 아닙니다. 진단에는 별도로 화면 제출 삼각형을 표시하며 이 값은 배우와 중복 렌더 패스를 포함합니다. 편집 대상은 메시 인덱스를 확인할 수 있을 때만 표시합니다.
구현 · 시각 미확인입장 시 캐릭터 정면새로 입장할 때 카메라를 정면으로 설정합니다. 저장 위치 복귀나 지역 이동 중 기존 시점은 유지합니다. 실제 화면 구도는 미검수입니다.
구현 · 시각 미확인소지품 · 의뢰 · 이야기창의 머리말과 탭을 줄이고 소지품 영역의 비율을 넓혔습니다. 작은 화면 및 항목별 가독성, 요청한 85%의 실화면 달성 여부는 미검수입니다.
수정 · 파일 재현 미확인저장 컷씬 열기같은 장면을 다시 열 때 끝 시점을 물려받지 않고 처음부터 시작하도록 수정하고 닫기 버튼을 추가했습니다. 문제를 일으킨 실제 업로드 파일로 재현하지 못했습니다.
부분 구현편집기 고정 도구 · 닫기맵 편집에는 되돌리기·다시하기·브라우저 저장·게임 복귀·닫기 고정 도구를 추가했습니다. 배우 편집 및 컷씬 보기에도 닫기를 보완했습니다. 모든 제작 화면에 동일한 고정 도구가 적용된 것은 아닙니다.

검증 및 제한

관련 자동 회귀 검사와 NPC 삭제·복원, UI 미리보기·저장·오적용 방지 검사를 통과했고 배포용 빌드를 완료했습니다. Node와 Babylon NullEngine에서 확인한 결과이며, 브라우저 자동조작은 사용하지 않았습니다. 실제 그래픽 표시·입력·S23 프레임 및 발열은 확인하지 않았습니다. 비·눈 효과는 추가하지 않았습니다.

원본 텍스처와 기존 LOD, 전투 판정은 유지했습니다. 맵 고유 전체 삼각형 수는 일부 미등록·동적 에셋이 집계되지 않아 확인 가능한 합계와 화면 제출량을 구분해 표시합니다.

외부 이미지나 스크립트 없이 이 HTML 하나로 공유할 수 있습니다.
