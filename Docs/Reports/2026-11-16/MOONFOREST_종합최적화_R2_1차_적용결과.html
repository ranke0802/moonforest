확인한 수치와 해석

  • 전사 동작: 실제 배포 클립으로 162번 전환, 1,944개 포즈 비교, 258개 타격 궤적 샘플 및 140번 빠른 전환을 확인했다. 포즈 오차 0, 타격 궤적 동일.
  • 캐시 2 → 4: 누적 바인딩 생성 35,088 → 26,112, 약 25.6% 감소. 안정 후 보존 바인딩은 1,224 → 2,040으로 816개 증가한다. 생성 집중 완화와 메모리·순회 비용의 교환이며, 전환 CPU 시간이나 실제 FPS가 빨라졌다는 증거로 사용하지 않는다.
  • 80개체 분산 조건: 기존 두 순회는 총 6,320쌍을 검사한다. 공간 후보 방식은 떨어진 개체의 불필요한 거리 검사를 생략한다. 이 조건은 밀집 전투의 성능 수치가 아니다.
  • 실제 마녀: 724개 포즈에서 약 2,952만 정점 위치를 비교해 경계가 스킨·모프 변형을 포함하는지 검사했다. 외곽선의 화면 가장자리, 회전·배율, 반복 복귀도 검사했다.

아직 적용하지 않은 조건부 작업

W04 추가 thin instance와 W05 지형 분할은 드로우콜·삼각형 감소의 교환을 확인하는 작은 시범부터 진행해야 한다. 현재 맵 전체를 다른 구조로 바꾸지 않았다. W10 교차 로더 입장 제어는 기존 공유 2ms 준비 경로를 유지한 채, 실제 긴 GPU 제출과 겹치는 작업을 식별한 뒤 도입해야 한다. W11 디코더·고해상도 캐시 보존 실험도 메모리와 준비 세션 종료 조건이 필요해 기본 정책을 유지했다.

NPC 시간원 통합, 모든 소유자를 강제하는 전역 자원 입장 상한, 향후 탑·하우징·PvP·대규모 마법 효과 예산은 후속 항목이다. 이번 소유 비용 관측은 그 준비 단계이며 해당 기능들이 구현됐다는 의미는 아니다.
