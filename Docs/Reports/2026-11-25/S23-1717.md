# S23 0.3 마을 왕복과 고블린 침공 검수

2026-11-25 17:04~17:17 KST에 수동 종료한 `moonforest-performance-2026-11-25T08-17-00-452Z.json`을 아스트라와 페이블 5.2가 독립 판독했다. 공개 커밋 `1a8bb974`의 부팅 청크와 0.3 청크가 기록 양 끝과 일치한다. S23의 Adreno 740, WebGL 2, 높은 화질, 내부 해상도 1354×652, 목표 60 FPS 조건이다.

방문할 때마다 마을이 계속 느려지지는 않았다. 마지막 마을에서 도보 교전으로 잡힌 7개 1초 구간은 239프레임, 38.2 FPS였다. 마을 기승 구간은 54.7 FPS, 대평원 기승은 58.9 FPS였다. GPU 시간 쿼리가 지원되지 않아 제출에 걸린 CPU 시간을 GPU 실행 시간으로 환산할 수 없다.

## 우선순위와 근거

1. **마을 침공 준비와 실제 교전.** 고블린 네 마리의 첫 소환은 2.009초였다. 원본 준비 594ms, 숨은 개체 준비 1,372ms가 기록됐고 후자에는 프레임 양보를 기다린 1,109ms가 포함된다. 수정본은 M05 목책 경고를 열었을 때 같은 모델 라이브러리에 원본을 요청한다. 대화를 닫아야 실제 소환이 시작된다. 다른 저장으로 첫 마을에 간 것만으로 고블린을 준비하지 않는다. 플레이 중 554.8초의 249.6ms 간격은 직전 JS가 32.4ms였다. 소환 대기 시간이나 보상 저장만으로 설명할 수 없다.
2. **같은 탭의 지역 전환.** 이번 기록의 첫 진입과 다섯 번의 이동에서 게임 리소스 다운로드 계수는 모두 0바이트였다. 다섯 번의 이동마다 보관된 키 1,270개를 전부 열거했고 그 작업 시간 합은 9.45초였다. 실제 각 이동 전체는 5.76~8.42초였다. 수정본은 이전 전체 조회 비용과 현재 지역에 필요한 파일 수를 보고 현재 캐시에 해당 URL만 조회한다. 개별 조회가 느리면 전체 조회로 돌아간다. 세 지도 준비 경로의 다섯 번 방문을 재생한 로컬 검사에서 전체 열거가 5회에서 1회가 됐다. 9.45초는 기존 조회 비용의 총합이며 예상 단축량이 아니다.
3. **대평원 전투의 순간 정지.** 235.33초에 회색 늑대 한 마리의 전체 갱신이 155.1ms였다. 이때 기상 클립은 전후가 같았고 길 찾기 계수는 0이었다. 432.75초에 세계 갱신 226.0ms가 포함된 프레임 다음 간격은 290.1ms였다. 이 시점의 최근 KTX 업로드는 약 11초 전이다. 다음 기록에서 카메라, 몬스터 표시 범위, 시야 가림, 풍경 표시 갱신과 느린 개체 상태를 분리해 본다. 늑대의 기상·추격·첫 공격 타이밍을 유지한다.
4. **지속 비용과 메모리.** 말 위 자세 계산은 평균 0.28ms였다. 고삐가 두 손의 공통 관절을 다시 계산하던 일을 제거했다. 같은 전사·말에서 프레임당 행렬 계산 111→102회, 승하차와 이동 1,710프레임의 최종 정점 바이트가 일치했다. 마을 스냅샷에서 대장장이의 4096² 색상 텍스처는 밉 포함 85.3MiB로 추정됐다. 이는 엔진의 텍스처 추정량이며 기기 전체 점유량이나 FPS 손실량을 뜻하지 않는다.

## 대장장이 텍스처 비교

마을 대장장이의 색상 원본은 4096² JPG였다. 같은 크기의 UASTC KTX2로 13개 밉을 유지했을 때 ASTC 4×4 디코더 출력 합은 22,369,648바이트(21.3MiB)다. 기존 RGBA8 전체 밉 추정치와의 차이는 64MiB다. 최고 해상도를 실제 ASTC로 복원해 비교한 PSNR은 51.82dB였다. 얼굴, 수염과 앞치마를 포함한 모델 3면도 대조했다. 파일 자체는 2,884,959바이트에서 15,378,788바이트로 커져 처음 받을 때 11.9MiB를 더 쓴다. 전송량, 압축된 텍스처 크기, 게임 프로세스 전체 메모리는 각각 따로 검수한다.

## 이탈과 진단 비용도 확인한 항목

- 목책 경고 도중 타이틀로 돌아가거나 다른 지역을 열면 진행 중인 고블린 원본 준비를 취소한다. 매니페스트 응답을 지연시킨 실제 게임 로더 검사에서 두 경로 모두 이탈 후 모델 요청 0회, 남은 개체와 원본 컨테이너 0개였다. 다른 소환이 같은 요청을 이어받았을 때에는 한 번 준비한 원본을 함께 사용했다.
- 다음 기록은 한 프레임 안에서 엔진이 알린 WebGL 셰이더 컴파일 시도와 두 관측 프레임 사이의 시도를 따로 센다. 캐시에서 관측한 셰이더 이름에는 관측 시각을 기록한다. 이름을 특정 컴파일과 직접 연결할 수는 없다. 컴파일 이벤트가 없는 100프레임에서는 초기 기준 목록을 읽은 뒤 추가 열거가 0회였다.
- 같은 엔진에서 마을과 대평원을 네 번 왕복한 로컬 검사에서 후반 마을은 메시 1,553개와 지오메트리 21개, 평원은 메시 2,674개와 지오메트리 12개로 유지됐다. 실기기 프로세스 메모리는 이 검사로 측정할 수 없다.

## 같은 저장으로 확인할 것

M05 침공 전 저장 사본을 둔다. S23에서 성능 기록을 켜고 평원 늑대를 처음 때린 뒤 2초까지 진행한다. 마을→평원→마을을 같은 순서로 오간 뒤 목책 경고 대화, 고블린 네 마리 처치, 청년 대화, 마을 광장 30초까지 한 파일에 기록한다. 평원 무리에서 카메라를 급회전해도 추격과 첫 타격이 이어지는지 본다. 지역 로딩의 총시간·캐시 조회·전송 바이트, 대화 종료부터 소환 가시화까지, 가림막 밖 첫 타격 전후 2초 최악 프레임과 새 셰이더·업로드를 별도로 비교한다. iPhone은 침공 직전부터 청년 대화가 끝난 뒤까지 같은 저장·화질로 비교한다. 이 S23 기록에는 iPhone 실측이 없다.
