# v4.17 · 성능과 입력 회귀 수정

## 변경

- Retina 창에서 숲을 원래 해상도로 모두 그리던 비용을 줄였다. 창·UI·마우스 좌표는 유지하고 3D 렌더만 종횡비를 유지한 최대 1600×1000으로 제한한다. 창 크기 변경, 카메라, 미니맵과 환경 그림자 토글은 유지한다. 큰 창에서는 3D가 원본 해상도보다 부드러워질 수 있다.
- 퀘스트 적의 감지 범위를 5→7m, 귀환 경계를 7→12m로 조정했다. 플레이어에게 맞으면 10초간 원거리 공격자에게도 반격한다. 무한 추적은 하지 않으며 귀환 경계를 유지한다.
- 위치 J 에너지볼은 발사 시 선택한 적을 비행 중에도 추적한다. 마우스 공격은 지정 방향을 유지한다. 지면 높이 적응/넓은 수직 판정은 유지하고, 마법 차단은 실제 벽·고체 소품 레이어로 한정한다.
- 이름 칸은 포커스를 잃기 전 한글/일본어 조합 문자열을 보존한다. 게임 중 IME 조합을 끄고, 이름·개발자 숫자 입력 때 활성화한다.
- BGM 소스가 완전히 중단된 경우 UnPause만 반복하지 않고 재생을 복구한다. 사용자의 음량·음소거 설정은 변경하지 않는다.
- 시작화면에 v4.17 표기를 추가했다. U/I/K, C/B/V, Z 단축키는 유지한다.

## 검증 범위와 한계

이전 모험 검사는 퀘스트 진행을 위해 AI를 정지시켜 실제 적 이동을 검증하지 않았다. 이번에는 `--adventure-verify <folder> --live-ai`로 원래 숲의 몬스터 Update/CharacterController를 실행한다. 길목 4, 정화 4, 정예 3체를 검사한다. 넉백은 이동 또는 실제 측면 충돌에 의한 정지를 인정한다. 초기 진단에서 밀집한 적의 충돌을 이동 실패로 판정한 항목을 수정했다.

고해상도 진단(3600×2160)은 수정 전 약 28FPS, 수정 후 약 58~59FPS였다. 수정 후 1920×1080에서는 약 60FPS였다. 짧은 로컬 구간 측정이며 전체 맵의 60FPS를 보장하지 않는다.

전용 게임 프로세스에 macOS 키 이벤트를 보내 C/B/V 창 열기·닫기, Z/U/I/K 입력, J 차징·발사를 확인했다. 한글 마지막 음절·자모·커서 중간 조합은 코드 회귀 검사로 확인했다. 모든 macOS 입력기의 실제 조합 동작까지 검증한 것은 아니다.

기존 저장, 이름, 오디오 설정을 삭제하지 않는다. 테스트는 별도 테스트 저장 키를 사용하고 기존 값을 복원한다. 기존 v4.15/v4.16 앱도 보존한다.
