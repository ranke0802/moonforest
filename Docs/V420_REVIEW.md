# 달빛숲 v4.20

- 방향키 또는 WASD: 메뉴·선택지 이동. E/J: 확정.
- 이름을 입력 중일 때는 WASD도 글자로 입력합니다. Enter로 입력을 마친 후 메뉴를 이동하세요.
- 선택 항목은 보라색 외곽선, 밝은 민트색 테두리로 표시합니다.
- 레벨업·유물 선택은 카드 전체 테두리와 ‘선택 중 · E/J’ 표식을 표시합니다.
- 화면 오른쪽 위에서 v4.20을 확인할 수 있습니다.

검증: 메뉴 회귀 22개 + 실제 macOS 키 입력(E W S E → D A 방향키 J) 3개, 총 25개 통과. 빌드 오류/경고 0, 셰이더 오류 0, 실행 오류 0. 별도 테스트 저장을 사용했으며 사용자 저장 데이터는 수정하지 않았습니다.
