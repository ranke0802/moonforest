# v4.16 · 퀘스트 표식과 조작

- 루미 머리 위에 새 의뢰 `?`, 의뢰 완료 `!`를 표시한다. 완료 알림을 저장하며 루미와 대화하면 다음 의뢰 `?`로 바뀐다. 진행 중에는 숨기고 모든 의뢰 완료 시 `!`를 유지한다.
- 스킬 순서대로 U/I/K, 상태창 C, 인벤토리 B, 스킬창 V, 카메라 복원 Z. HUD·스킬창·안내판·개발자 카메라 안내와 시전 취소 감지 키도 함께 변경했다.
- 전사 J/좌클릭 공격은 매 타격 시작 시 가장 가까운 공격 가능한 생존 적을 선택한다. 18m 내에서 벽 너머와 높이 차 3m를 넘는 적을 제외하며, 기존 전진량·3단 콤보·치명타·넉백은 유지한다. 대상이 없으면 현재 방향으로 공격한다. 대상 발밑 표식도 표시한다.
- 모험/표식/저장 검사 204개 통과, 전투·접지·애니메이션 검사 119개 통과, 실행 오류 0개. 전사 방향 전환, 실제 접근 이동, 다음 타격의 재선택, 벽 뒤 적 제외, 적이 없을 때의 동작을 포함한다. 최종 빌드 오류·경고 0개.
- NPC의 `?`/`!`와 갱신된 단축키를 게임 화면 캡처로 확인했다. 미변경 오디오 전체 검증은 이번 버전에서 반복하지 않았다.
