최우선: 실제 텍스처와 형상 품질

배경·몬스터·NPC·소품 등 신규 생성과 제작, 기존 에셋 감량 모두에 적용합니다.

실제 색상 텍스처를 적용한 결과를 정면·측면·사선, 가까운 거리와 축소 거리에서 원본 또는 승인된 디자인 기준과 비교합니다. 무늬의 늘어짐·뒤집힘·잘못된 색상 연결, UV 이음새·겹침·패딩, 실루엣·구조·떠 있는 부품을 먼저 확인합니다. 체크 무늬와 표면 대응 검사도 함께 사용합니다. 신규 자산은 생성 직후의 원본과 승인 디자인을 기준으로 비교합니다.

  1. 텍스처 해시 일치나 일부 정점 UV 바이트 일치만으로 외형 보존을 판정하지 않습니다. 실제 재질/텍스처가 연결된 모델로 검토합니다.
  2. 새 UV에 원본 색상을 재투영하면 원본 이미지를 보관하고 후보 이미지의 출처·해상도·해시·변경 사실을 기록합니다. 원본과 픽셀이 동일하다고 표시하지 않습니다.
  3. 변환 결과의 색상·알파는 원본과 비교하여 검증하며, 무손실 형식이라도 실제 디코딩 픽셀을 확인합니다. 차이가 있으면 검증된 대안을 사용합니다.
  4. 각 LOD, 모바일·고해상도 프로필, 밉맵 및 축소 거리에서 해당 UV와 텍스처가 짝이 맞고 이음새가 튀지 않는지 게임 반영 전 확인합니다.
  5. 품질을 지키기 어려운 목표치는 무리하게 맞추지 않고 실제 삼각형·정점·버퍼 수치, 남은 시각 차이와 초과 사유를 기록하고 개별 검토합니다. 삼각형 감소만으로 FPS 개선을 주장하지 않습니다.

제외 항목과 개별 예외

보라 천막 노점, 채소·꽃 텃밭, 수동 권양기·핸들, 연금술 작업대, 소박한 침상은 R2 감량에서 제외했습니다. 집·예배당, 감시탑, 마을 외경과 기존 건물·성벽, 다른 일반 나무와 천 덮개 짐마차도 이전 지시에 따라 제외합니다. 고사목은 이번에 별도 승인된 예외입니다. 마을 외경 village-approach 단일 외피는 R2 20종과 별도로 승인되어 로컬 매니페스트에 적용되었고 통합 빌드를 통과했습니다. GitHub 배포 여부는 별도로 확인합니다. 이 승인은 마을의 개별 집·예배당·나무나 기존 성벽을 감량할 권한을 뜻하지 않습니다. 후보 실제 메시 높이는 약 23.13m로 기존 9.93m보다 높고, 사용자가 승인한 뾰족한 부분을 포함합니다. 기존 native height/bounds 비율과 배치·충돌·카메라·LOD 선택은 유지합니다. 승인된 모델의 실제 AABB를 기존 좌표 변환으로 투영해 스트리밍 수요 범위에 포함합니다. 해당 배치의 수요 구 반경은 약 84.87→86.58로 넓어져 경계 시야에서 모델 요청 시점이 달라질 수 있지만 LOD 임계값과 모델 배율은 변경하지 않았습니다. 전 프로필 4K 텍스처는 GPU 메모리 사용량을 늘릴 수 있으며 실기기 FPS·발열·메모리와 수요 범위 변경의 성능 영향은 미측정입니다. 원본과 기존 리소스는 사용자 결정 전 삭제하지 않습니다.

사용자 승인 당시의 시각 검수와 Node/NullEngine·정적 검사는 GPU 실화면, 장시간 FPS 또는 발열 측정이 아닙니다. 데이터와 근거를 함께 확인합니다.
