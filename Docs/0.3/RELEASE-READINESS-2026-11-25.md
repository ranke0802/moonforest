## 재현 수치와 한계

11월 25일 사용자 제공 S23 장기 기록 `T00-37-01-924Z`에서 로딩 가림막이 걷힌 초만 골랐다. FPS는 총 프레임 수를 해당 프레임 간격 합으로 나눴고, CPU 시간은 프레임당 평균이다. 같은 장면에 포함되는 렌더 제출 시간과 장면 시간은 서로 더할 수 없다.

- **맵 전환 메모리.** 실제 7종으로 동일한 기하 메모리 추정치를 얻으면서 스킨 속성을 임시 실수 배열로 풀던 작업을 없앴다. 평원 19마리 기준 누적 6,787,008바이트, 최초 종 준비까지 포함하면 9,614,736바이트의 임시 할당을 피한다. 기기의 상주 GPU 메모리 감소량은 별도로 측정해야 한다.
- **해제.** 로컬 엔진으로 평원↔마을을 네 번 왕복했다. 각 평원 해제 때 몬스터 메시 88, 지오메트리 32, 스켈레톤 19, 애니메이션 그룹 414가 모두 0이 되었다. 강제 GC 뒤 JS 힙은 107/106/107/106MiB. 첫 여우·곰 일부 참조는 셰이더 캐시에 남았다. iOS의 프로세스 메모리와 강제 종료 기준은 이 실험에서 알 수 없다.
- **풍경 해제.** 550개 빈 루트를 섞어서 제거하면 등록 위치를 찾는 선형 검색이 550회였다. 등록 위치를 기억하는 방식은 같은 입력에서 검색 0회로 같은 메시 목록을 돌려준다. 매 프레임 가시성·그림자·텍스처 등급은 동일하다.
- **캐시 A/B.** S23의 최근 방문 8회의 맵 준비 목록 전송은 0바이트였지만 저장된 1,270개 키 열거에는 방문당 1.37~2.24초가 들었다. 선택 실험 `?cacheProbe=1`은 필요한 URL의 키만 네 개씩 조회한다. 다른 작업과 겹치므로 열거 시간 전체를 로딩 단축 예상치로 잡지 않는다. 기본 경로와 같은 최초·재방문 맵/기기/빌드에서 비교한다.
- **배포.** 전투 수정 공개 SHA `1e39c7f5`의 0.3 manifest는 2,434개·895,690,654바이트다. 개별 버전의 목록 크기이며, 0.1~0.4 전체 합집합·방문당 전송·아이폰 메모리는 각각 따로 센다.
- **구형 테스트.** 이번 0.3 추격과 별개로, 0.2 알파 늑대 r13의 넉백·방패 경계 검사 3개가 직전 커밋에서도 동일하게 실패했다. 승인된 구형 버전의 동작을 바꾸려면 따로 비교해야 한다.

## 검수 범위와 재현

- 공개 0.3의 부팅/셸 → 슬롯/이어하기 → 평원·마을·숲·동굴 → 사망·장면 전환·중단/복귀 경로를 대상으로 삼았다. 구매·장비·단련·전리품·퀘스트도 인접 회귀에 포함했다. 배포 CI 목록 96개 파일을 로컬에서 함께 실행해 구·신 버전 저장 회귀 2개를 포함해 543개 테스트가 모두 통과했다.
- 저장 고장 주입은 실제 `GoldLoot`, 슬롯 저장소, 1장 퀘스트/의뢰 정의, 대화 이벤트로 실행했다. 같은 탭 재시도·두 슬롯·다시하기·낡은 저장과 새 저장의 차이를 검사했다. 브라우저 게임 자동화는 사용하지 않았다. 재현 테스트는 `v03-quest-settlement.test.js`, `v03-talk-stage-trail.test.js`, `v03-low-melee.test.js`에서 다시 실행할 수 있다.

## 오퍼스 교차 버전 검수

- 실제 이전 0.3 `1e39c7f5`와 0.3 `a1cbbaf8`를 같은 저장 슬롯에 연결했다. 첫 퀘스트 보상 30G를 회복약 2병에 전부 쓰고 세 번 재시작한 결과는 매번 0G·물약 6병·60XP였다. 먼저 열어 둔 옛 탭의 거래는 충돌을 감지했고 최신 잔액을 보존했다.
- 배달 퀘스트 S03에서 보상 저장 직후 앱 종료 → 이전 클라이언트에서 같은 슬롯을 열어 상점 거래 → 현버전으로 복귀하는 순서도 시험했다. 옛 클라이언트가 보상 영수증 필드를 지워, 고기를 이미 건넨 플레이어에게도 같은 의뢰가 활성으로 남았다. 퀘스트별 경험치와 해당 GOLD 전액의 지급 기록이 모두 남으면 재접속 시 영수증을 복구한다. 수정 후 S03은 고기 0개로 즉시 완료됐으며 세 번 재시작한 뒤에도 16G·물약 4병·65XP를 유지했다. 한쪽 기록만 있는 경우는 완료로 바꾸지 않았다.
- 이전 바이너리에서 직접 의뢰를 다시 완료해 이미 변한 소모품 수량은 당시 상점·배달과 각각 구분할 수 없다. 출처가 불명확한 수량을 소급해서 고치면 정상적으로 쓴 플레이어에게도 영향이 간다.
- 배포 기준 `a1cbbaf8`에서 두 Pages 작업이 성공했고, 공개 manifest의 0.3에는 2,435개 파일·895,708,454바이트가 있었다. 공개 HTML·셸·엔트리 스크립트·크레딧의 실제 응답 90개가 모두 SHA-256과 일치했다.
