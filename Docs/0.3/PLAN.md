# MoonForest 0.3 계획

목표: 1장(전사 편) + 2장(엘레나 편)을 상용 품질로 완성한다. 시놉시스 기준은
`MOONFOREST_통합시놉시스_회귀와선택_개정판_2026-11-10.html`(사용자 보관)이다.

## 제품의 약속 (모든 판단의 기준)

1. **첫 1분**: 로고 → 타이틀 → 15~20초 꿈 오프닝 → 바로 첫 전투. 새로하기를 누른 뒤 로딩이 없어야 한다.
2. **첫 10분**: 첫 전투 → 마을 도착 → 여관 → 증언 3개 → 첫 의뢰 → 첫 장비 교체. 10분 안에 성장 한 번을 겪는다.
3. **전투가 주인공**: 전조를 읽고, 막거나 피하고, 반격한다. 연속기와 궁극기로 보상을 준다.
4. **느려지지 않는다**: 콘텐츠를 더해도 프레임이 유지되는 구조를 먼저 만든다.

순서 이유: M0·M1로 "첫 1분"을 먼저 손에 잡히게 만들고, 콘텐츠를 늘리기 전에 M2로 비용 구조를 고친다.
M3·M4는 서로 독립이라 사용자 검수 대기 중에 다른 쪽을 진행할 수 있다.
