## 1. 시작 흐름

```
[로고] HYProduct (검은 화면, 1.4초 나타남 → 1.2초 유지 → 1.4초 사라짐, 아무 키로 건너뛰기)
   ↓
[타이틀] 어둡게 처리한 실제 전투 장면(전사 vs 우두머리 늑대, 느린 선회 카메라)
         새로하기 / 불러오기 / 갤러리 / 설정 / 끝내기
   ↓ 새로하기 (로딩 없음: 타이틀이 이미 대평원을 띄워 두었다)
[오프닝 15~20초] 꿈: 치유하는 손 → 청년 → 습격 → 응답 없는 기도 → "그 아이를 찾아라"
   ↓
[첫 전투] 마차가 급정지한다. 마부: "늑대다! 용병 양반!" 회색 늑대 2마리.
          조작 안내는 상황에 맞춰 한 줄씩(공격 → 회피 → 방어). 실패해도 마차 옆에서 즉시 재개.
   ↓
[복선] 언덕 위 우두머리 늑대가 내려다보다 돌아선다.
   ↓
[마을] 정문 → 달빛 여관(휴식·저장·게시판) → 증언 수집 시작
```

- 마차는 유지하되 "이동 연출"이 아니라 "습격당하는 장소"로 쓴다. 이미 있는 `covered-wagon` 자산을 쓴다.
- 여관은 거점이다. 침대에서 쉬면 저장·회복·시간대 전환이 된다. 2장에서 같은 여관의 과거 시점을 쓴다.
- 꿈의 1차 구현은 실루엣·빛·자막 중심의 짧은 연출이다. 요아힘 모델이 오면 엔진 컷씬으로 교체한다.

### 타이틀 메뉴
| 항목 | 동작 |
|---|---|
| 새로하기 | 빈 슬롯 선택(3칸) → 오프닝. 진행 중인 슬롯은 덮어쓰기 확인 |
| 불러오기 | 슬롯 목록(장·위치·플레이 시간·레벨). 없으면 비활성 |
| 갤러리 | 본 컷씬 다시 보기, 만난 몬스터 도감, 칭호. 처음에는 잠김 표시 |
| 설정 | 기존 설정 창 재사용(화질·해상도·프레임·음량·조작) |
| 끝내기 | 확인 후 종료 화면. 웹에서는 창을 닫을 수 없으므로 "종료되었습니다" 화면 |

## 2. 1장 퀘스트 줄기

메인은 한 줄로 이어진다. 각 단계가 다음 장소와 이유를 준다. 선택 의뢰는 게시판에 모은다.

| ID | 이름 | 장소 | 핵심 | 주는 것 |
|---|---|---|---|---|
| P0 | 꿈 | — | 오프닝 컷씬 | — |
| M00 | 늑대와 마차 | 대평원 길 | 첫 전투, 조작 익히기 | 늑대 가죽, 회복약 |
| M01 | 달빛 여관 | 마을 | 여관 주인, 방 배정, 저장 | 지도, 게시판 해금 |
| M02 | 사람들이 기억하는 성녀 | 마을 | 증언 3개와 모순 기록 | 붕대, 저널 |
| M03 | 마을의 부탁 | 마을·평원 | 사냥·채집 의뢰 2개 이상 | 첫 장비(가죽 갑옷), 레벨 2 |
| M04 | 대평원의 곰 | 평원 언덕 | 첫 보스. 전조 → 방어/회피 → 반격 | 곰 발톱, 칭호, 요아힘 증언 해금 |
| M05 | 마을을 습격한 고블린 | 마을(밤) | 방어전. 방패병·궁수·주술사 | 마석, 홉고블린 정보 |
| M06 | 마물의 숲 | 숲 | 홉고블린, 마석 강화 소개 | 강화 재료, 동굴 위치 |
| M07 | 동굴의 실험실 | 동굴 | 구울 전사, 기관, 연구 기록 | 기록 조각 |
| M08 | 타락의 성소 | 동굴 성소 | 엘레나 인간형 → 마물형 | — |
| M09 | 남겨진 방과 일지 | 성소 | 비비앙 개입, 일지 회수, 엔딩 | 2장 해금 |

- 기존 `chapter-quest-data.js`의 M00~M09·Q01~Q09를 이 줄기에 맞춰 0.3용 데이터로 다시 쓴다(0.2 데이터는 건드리지 않는다).
- 미구현 사유로 막혀 있던 Q03/Q08/M06(구울·홉고블린·반려동물)은 M5에서 해소한다.
- 엔딩 복선: 비비앙이 떠나며 동굴 깊은 곳의 "억제기"를 한 번 바라본다(0.4 게이트 설정의 씨앗).

### 인물별 말투와 선택 의뢰 (2026-11-24, 귀향 개정 반영)

전사는 몬트하임에서 자란 사람이라 모두가 이미 안다. 처음 말을 걸면 귀향 인사가 한 번 나오고(`NPCS.greet`), 그 뒤로는 짧은 평소 대사가 나온다. 누구든 자기가 직접 본 것만 말한다.

| 인물 | 말투 |
|---|---|
| 양아버지(교관) | 짧은 반말. 본 것만 말하고, 마음은 행동으로 보인다 |
| 마부 | 어릴 적부터 본 시골 어른. 정 많은 반말(-구나, -거라) |
| 여관 주인 | 무뚝뚝하게 끊어 말하는 반말. 말보다 자리를 치워 두는 사람 |
| 노년 여성 | 수다스럽고 다정하다. 밥부터 챙긴다(-구먼, -우) |
| 약초사 | 차분한 존댓말. 본 것과 들은 것을 꼭 나눈다 |
| 청년 | 동생뻘. 들뜬 해요체로 "누나"라 부르고, 요아힘은 "형" |
| 촌장 | 하게체. 신중하고 마을 책임 때문에 말을 아낀다 |
| 대장장이 | 투박한 장인의 반말. 쇠에 빗대 말한다 |

선택 의뢰(`ERRANDS`, `src/v03/errands.js`)는 메인 퀘스트 사이에 하나씩 열린다. 각 의뢰는 게임 기능 하나를 익히게 하고, 마치면 의뢰를 준 사람이 자기가 본 것을 하나 더 말한다. 메인을 막지 않고, 보상은 한 번만 준다.

| ID | 주는 사람 | 열리는 때 | 익히는 것 | 하는 일 |
|---|---|---|---|---|
| S01 | 청년 | M02 뒤 | 사냥과 전리품 | 대평원 짐승 두 마리 |
| S02 | 약초사 | M02 뒤 | 조제와 빠른 사용 | 받은 약초로 회복약 한 병 조제 |
| S03 | 노년 여성 | M03 뒤 | 재료 쓰임 | 멧돼지 고기 한 덩이 전달 |
| S04 | 대장장이 | M04 뒤 | 단련(타이밍) | 받은 쇳조각으로 한 번 단련 |
| S05 | 촌장 | M06 뒤 | 원거리 적 대응 | 숲의 고블린 궁수 둘 |
| S06 | 대장장이 | M06 뒤 | 동굴 전리품 | 구울 사슬 고리 전달 |

머리 위 표식은 `?`(메인 대화), `!`(보고·전달 가능), `+`(선택 의뢰 있음, 연보라)이다. HUD에는 메인 아래에 진행 중인 의뢰 하나를 작게 보인다.

## 3. 전투 개편 (전사)

현재: 찌르기·베기 / 베기 / 심판(길게) / 방패 밀치기 / 방어 / 회피 / 질주.

| 입력 | 새 동작 | 의도 |
|---|---|---|
| (대기) | 전투 자세: 방패를 앞에, 검을 낮게. 비전투 시 느슨한 자세 | "마음에 안 드는 기본 자세" 교체 |
| 공격 ×3 | 가로베기 → 올려베기 → 전진 찌르기 | 3타에 전진과 경직. 타이밍이 맞으면 이어짐 |
| 공격 길게 | 심판(1단) → 더 모으면 2단(범위·피해 증가) | 기존 유지, 단계 추가 |
| 공격 1~2타 뒤 강공격 | 방패 강타 → 내려찍기 | 연계 마무리. 쓰러뜨림 |
| 회피 직후 공격 | 돌진 베기 | 회피를 공격 기회로 |
| 방어를 맞기 직전(0.18초)에 시작 | 저스트 가드: 스태미나 소모 없음, 적 경직 | 숙련 보상 |
| 저스트 가드 뒤 공격 | 반격(치명타 확정) | 방어 → 반격의 쾌감 |
| 궁극기(게이지 100) | 서약의 일섬: 1.2초 연출 카메라, 3연 대베기 + 마무리 | 적중·저스트 가드로 충전 |

- 판정은 지금처럼 실제 검·방패 궤적과 몸 캡슐의 접촉을 쓴다. 큰 구로 덮지 않는다.
- 타격 연출: 히트스톱(약 0.05초 / 강 0.09초), 방향성 섬광, 짧은 카메라 흔들림, 숫자. 모두 유한 풀.
- 필요한 새 클립: 전투 대기, 비전투 대기, 3타 찌르기, 방패 강타, 내려찍기, 돌진 베기, 반격, 궁극기(8개).
  전사는 Mixamo 골격이므로 Mixamo의 Sword and Shield 계열을 1순위로 쓴다. 없으면 Blender로 직접 만든다.
- 적도 같은 문법을 쓴다: 전조(색·자세) → 공격 → 빈틈. 방어 불가 공격은 붉은 전조로 통일.

## 4. 성장·아이템·인벤토리

### 능력치 (5개만)
공격력, 방어력, 최대 체력, 최대 스태미나, 치명타. 레벨은 체력·스태미나만 조금 올리고, 힘의 대부분은 장비·강화에서 온다.

### 장비 8칸
검, 방패, 투구, 갑옷, 장갑, 장화, 장신구 2. 등급 5단계(일반·고급·희귀·영웅·전설, 기존 `loot-rarity.js` 색 사용).

### 아이템 종류
| 종류 | 예 | 쓰임 |
|---|---|---|
| 장비 | 가죽 갑옷, 곰 발톱 검 | 장착 |
| 재료 | 늑대 가죽, 곰 가죽, 뼈, 약초 | 제작(대장장이), 판매 |
| 마석 | 하급·중급·상급 | 장비 강화 +1~+5. 실패 없음, 비용만 증가 |
| 소모품 | 회복약, 붕대, 음식 | 전투 중 사용(슬롯 2), 음식은 일정 시간 버프 |
| 기록 | 일지 조각, 증언, 유품 | 저널에 정리. 팔 수 없음 |
| 염료·의상 | 염료 병, 망토 | 캐릭터 창에서 외형 변경. 능력치 없음 |

### 칭호
업적형. 작은 수동 효과 1개. 예: "곰을 넘은 자"(체력 +20), "상처 없는 사냥꾼"(홉고블린 무피격, 치명타 +2%). 메인 진행에 요구하지 않는다.

### 인벤토리 화면
- 격자 6×5, 종류 탭, 정렬. 선택하면 오른쪽에 설명·비교(현재 장비 대비 ▲▼).
- 데이터: `src/v03/data/items.js`. 인스턴스는 `{id, itemId, enhance, dye}`만 저장한다.
- 0.2의 가방·골드 저장과 분리된 0.3 세이브 문서 하나로 묶는다(부분 저장으로 생기던 불일치 제거).

## 5. 캐릭터 창

- 게임을 멈추고 **같은 scene**에서 카메라만 캐릭터 정면으로 옮긴다. 배경은 어둡게·흐리게(DOM 오버레이). 새 scene·RTT 없음.
- 드래그로 회전, 휠·핀치로 확대(얼굴~전신). 대기 자세 재생.
- 왼쪽: 장비 8칸. 오른쪽: 능력치와 변화량, 칭호. 아래 탭: 장비 / 외형(염색·의상) / 칭호.
- 염색: 의상 부위별 색상 곱(재질 uniform). 텍스처를 새로 만들지 않는다.

## 6. HUD·UI 원칙

- 전투 중: 체력·스태미나·궁극기 게이지(좌상), 보스 체력(상단), 소모품 2칸·조작 버튼(우하). 퀘스트는 한 줄로 접힘.
- 비전투: 퀘스트 추적 3줄, 미니맵, 상호작용 안내.
- 글자 최소 크기: 모바일 13px, PC 14px. 터치 대상 44px 이상.
- 글꼴은 게임 글꼴(`MoonforestUI`, Galmuri) 유지.
- 개발 도구(소환·패턴·진단·편집기)는 0.3 기본 화면에서 숨기고 `?dev=1`에서만 보인다.

## 7. 2장 (엘레나 편) 요약 설계

- 같은 마을·숲·동굴의 과거 상태: 무너지지 않은 목책, 살아 있는 요아힘, 건강한 숲. 배치 데이터의 "시점" 변형으로 만든다.
- 엘레나 조작 키트
  - 성녀: 빛의 일격(원거리 기본), 치유, 보호막, 정화(범위). 요아힘이 전방을 맡는다.
  - 흑마법(8절 이후): 저주 화살, 지배(고블린 주술사), 소환, 검은 폭발. 기존 엘레나 마법 모션 7종 재사용.
- 요아힘 동료 AI: 엘레나를 향한 적을 우선 막는다. 2절에서 "등을 맡길 수 있다"를 체험시킨다.
- 4~5절의 폭력은 직접 묘사하지 않는다. 화면 전환과 결과(성표, 빈 길, 숲)로 전달한다.
- 10절 끝에서 여관에 도착하는 전사의 뒷모습으로 1장 시작과 맞물린다.

## 8. 이후 버전의 씨앗 (0.3에서는 구조만)

- 0.4 게이트: 방어전 시스템(M05)과 파도 스폰 데이터 형식을 그대로 재사용한다.
- 0.5 생활: 여관 방 = 집의 원형, 시간대 전환 = 시계의 원형, 재료·제작 = 요리의 원형.
