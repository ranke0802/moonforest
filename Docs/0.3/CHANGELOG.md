# 0.3 변경 기록

## 2026-11-24 · 상태·가방·스킬, 상점과 아이템 언어

- 다섯 언어의 메뉴·상점·상자와 장비 표시를 추가했다. 강화 등급의 저장 ID는 유지하며 등급 이름만 번역한다.
- 스킬 창은 선택한 언어로 받은 조작 안내를 재사용한다. 물약·강장제 설명은 실제 효과와 지속 시간에서 숫자를 읽는다.

## 2026-11-24 · 마을 동물과 필드 상자

- 마을 길에서 강아지와 고양이가 걷고, 전령새는 뛰며, 지도를 든 쥐는 골목을 돌아다닌다.
- 상자를 처음 불러오지 못했을 때 가까이 머물면 다시 준비한다. 마을에서 보이지 않던 곰 언덕 바위의 원경 복사본 하나를 줄였다.

## 2026-11-24 · 1장 마을과 사냥

- 망루와 목책으로 입구를 보강하고 2층 여관을 배치했다. 곰 언덕의 충돌 지형을 보이는 바위와 맞췄다.
- 대장장이와 약초사에게 거래·제작을 연결했다. 무기 강화 결과에 따라 공격력과 최대 내구도가 바뀌고, 장착·전리품·복용 물약·보물상자 개봉 상태를 저장한다.
- 마부에게 받은 말로 야외를 이동할 수 있다. 마을에는 고향의 검술 교관을 배치하고, 주민 얼굴 앞부분에 섞여 있던 어깨 뼈 가중치를 교정했다.
- 숲에 고블린 전사·궁수·주술사·홉고블린을, 동굴에 좀비·구울 전사와 타락한 짐승을 배치했다. 지역을 벗어나면 준비 중인 개체와 활동 중인 개체를 함께 해제한다.

## 2026-11-24 · HUD, 가방·상태·스킬 및 풍경 준비

- 기존 게임 상태에 캐릭터 메뉴를 연결하고, HUD와 기록에 현재·최고 텍스처 메모리 추정치를 추가했다. 모바일 미니맵은 지형만 반투명하게 표시하고 정지 화면에 점멸 표식이 없으면 다시 그리지 않는다.
- KTX2로 대체된 배경 JPG 두 장의 중복 선준비와 일반 실시간 그림자에서 불필요한 시전자 분류를 줄였다.

## 2026-11-24 · 화면 밖 주민과 영역 몬스터

- 비전투 배회·휴식의 행동 갱신 간격을 늘리고 화면 밖 자세 샘플링을 생략했다. 카메라 회전, 그림자, 경계 진입과 전투 갱신을 검사하는 로컬 비교를 추가했다.

## 2026-11-23 · 최적화 1·3순위 측정 정리, 첫 프레임 NaN 방어

- 캐릭터 재질 고정(`v03/actor-material-freeze.js`)은 `?matfreeze=1`일 때만 켠다. 그려진 스킨 메시 재질만, 정의가 바뀌는 두 경로(재질·메시의 dirty 표시)에서 먼저 푼다. 검사는 프레임마다 400개씩 나눠 돈다. 배포본 켜기/끄기 픽셀 차이 0, PC 렌더 CPU 이득은 오차 범위라 기본값으로 켜지 않는다.
- 보스 계열 자세 보정이 첫 갱신 전에 불리면(dt 없음) 지면 높이가 NaN이 되어 몬스터가 사라지던 문제를 막았다(대평원 마차 튜토리얼 중 고블린 소환에서 재현).
- 측정 후 보류: 첫 공격 무기 자세 탐색(S23 최대 6.4ms·평균 0.02ms/프레임, 85ms는 11/20 수치), 곰 상수 채널(곰+장면 애니메이션 0.08ms), 풍경 thin instance(평원 후보 291개, 판정 0.22ms).

## 2026-11-23 · 텍스처 절감 1차 (일반 몬스터 2K 시험, PC 플레이어 4K, 진단 보강)

- 일반 몬스터 5종(회색늑대·늑대2·늑대3·여우·멧돼지)의 4K KTX2에서 맨 위 단계만 뺀 2K 파일을 만들었다(`scripts/trim-ktx2-top-level.mjs`, 원본의 2K 단계와 바이트 단위 동일). 0.3 기본값(`?monstertex=4k`로 4K). 배포본 같은 프레임 비교: 평소 거리 픽셀 차이 0, 화면을 채운 근접 최대 14/255(PSNR 66.4dB). 보스(알파 늑대·엘레나·애도)는 4K 유지. 5종 합계 내려받기 53.8MB → 18.3MB.
- 0.3 PC 플레이어 기본 텍스처를 8K 압축 → 4K 압축(`warrior-v3-mobile4k`, 지오메트리 동일)으로 바꿨다. 0.2 PC는 8K 그대로. 원본 선택지는 남는다.
- 고블린 색상 PNG(2048)를 KTX2(UASTC, 아스트라 변환)로 불러올 때 바꿔 끼운다. GPU 약 21MB → 5.6MB.
- 성능 기록에 초당 GPU 텍스처 MB·비압축 MB·텍스처 수·적응 단계, 메타데이터에 이동·공격 속도 설정을 남긴다. 보스 전투가 끝나면 보스 프로필 값을 0으로 돌린다(지난 전투 값이 남던 문제).

## 2026-11-23 · PC UI 배율·가이드 3줄·대화 원화

- 1280×720보다 큰 PC 창에서 HUD·퀘스트·가이드·대화창·메뉴·HUD 편집 창을 같은 비율로 키운다(`v03/ui-scale.js`, CSS zoom, 최대 3배). 확대 패널의 화면 단위는 배율로 나눈다. 폰은 그대로다.

- 검수 후 보완: `#app`에 둔 HUD 크기 변수(`--hud-v1-edge` 등)의 화면 단위도 배율로 나눈다(큰 창에서 여백이 두 번 커지던 문제). 적 체력바(`.boss-hud`)도 확대에 넣었다.
