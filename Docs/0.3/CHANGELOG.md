## 2026-11-27 · 선택 의뢰 쪽 넘기기·빛무리 대상·여관 선택창·캐릭터 텍스처 2K (화면은 검토 페이지로만 확인)

## 2026-11-26 · 상점 주민 대화창 통일 (화면 미확인)

- 대장장이·약초사도 다른 주민과 같은 창(원화 + 이름 + 인사 한 줄)으로 연다. 선택지는 세로 목록 대신 "다음/닫기" 자리에 같은 모양의 버튼 한 줄로 둔다(대화하기 / 상점 / 장비 재련 / 대화 종료). 세로 목록이 원화를 가렸기 때문이다.
- 선택지 문구를 짧게 바꿨다(5개 언어). 인사 대사 `smith-menu`·`herbalist-menu`를 새로 넣었다. 기존 idle 대사는 "대화하기"에서 다시 나오므로 겹치지 않게 했다.
- 2차(같은 날, 사용자 반려 반영): 선택 버튼은 "닫기" 버튼과 같은 규칙(크기·여백·글자)을 그대로 쓰고 오른쪽 아래에 나란히 둔다(대화 종료가 닫기 자리). 상자 아래 여백을 두 상태에서 같게 하고 본문은 두 줄 높이를 확보해, 인사 → 대화 → 선택지로 오갈 때 상자 크기가 바뀌지 않는다.
- 네모 E 표시를 없애고 이름 줄 오른쪽에 작은 글자("E 다음/닫기", "WASD 이동 · E 선택")로 키를 안내한다(터치에서는 숨김). 터치에서는 키를 쓰기 전까지 선택 강조를 보이지 않는다.
- 대화창은 닫을 때 다음 화면 갱신 직전까지 기다린다. 그 사이에 같은 창으로 대사나 선택지가 이어지면 닫지 않는다(그림·상자가 다시 나타나는 깜박임 제거).
- 대장장이 원화가 없어 빈칸이던 것을 대장장이 시트(`driver.webp`)로 연결했다. 새 마부 원화가 나올 때까지 마부와 같은 그림을 쓴다.

## 2026-11-26 · 별빛 강타 차징 피해와 착탄 가시성

- 버튼을 놓은 순간의 게이지가 각 타의 피해를 결정한다. 기본 강공격을 100%로 두고, 레벨별 완충 피해는 120·140·160·180·200%다. 5레벨 반충전은 150%이며, 훈련 허수아비의 숫자도 실전 정면 타격과 같은 방식으로 반올림한다.
- 공개판에서 지면 효과가 사라진 원인은 WebGL 2 셰이더의 예약어 충돌이었다. 변수명을 바꾸고 배포 검사에서 야외·동굴용 검광과 지면 효과의 셰이더를 링크한다. 균열은 착탄 첫 프레임에 열리고, 금빛 섬광과 파편이 대상 바깥으로 퍼진다.
- 동굴에서는 균열이 시야 경계를 걸쳐도 보이는 부분은 남도록 기존 동굴 안개 마스크를 적용한다. 차징 중인 검의 가시성도 현재 손과 칼끝의 위치를 기준으로 판정한다.
- 착탄 직후 섬광과 충격파가 지나간 자리에 어두운 단면이 드러난다. 균열 가장자리의 금빛과 떠오르는 별이 먼저 식고, 남은 틈은 4~5초 사이에 좁아지며 닫힌다. 충전량에 따라 돌이 튀는 높이, 가지 수, 빛의 세기가 달라진다.

## 2026-11-25 · 성능 기록이 멈춘 부분의 이름을 남긴다 (S23 17:04 기록 판독)

- S23 기록에서 세계 갱신 226ms·98ms, 그리기 제출 64~143ms 프레임이 있었지만 어느 부분인지, 새 셰이더가 만들어졌는지 기록에 없었다. 원인은 아직 미확정이다.
- 기록 항목 추가(진단을 켜고 수집 중일 때만): `worldCameraMs`·`worldRangeMs`(몬스터 표시 범위·동굴 안개)·`worldOcclusionMs`(나무 가림)·`worldVisibilityMs`(마을 가시성·풀밭), 처치 보상 처리 `defeatMs`, 게임 프레임 안의 WebGL 셰이더 컴파일 요청 횟수 `shaderCompileAttempts`와 직전 프레임이 끝난 뒤의 횟수 `shaderCompileAttemptsBetweenFrames`. 그 프레임에서 가장 느린 몬스터에는 길찾기 시간·새로 시작한 애니메이션 수·화면 밖 휴면에서 깨어났는지·원거리 여부·모드 전환을 함께 남긴다(`slowFoe.navMs/animatablesAdded/woke/far/modeFrom/mode`).
- 셰이더 횟수는 수집 중 Babylon WebGL 컴파일 이벤트를 받으면 증가한다. 일시정지·지역 전환·엔진 교체 시 구독과 관측 이력을 정리한다. 컴파일 요청이 있었던 프레임에는 캐시에서 새로 관측된 Effect 이름을 `context.recentShaderEffects`에 최대 12개 남긴다. 관측한 Effect는 약한 참조로만 추적한다. 이벤트가 이름을 제공하지 않으므로, 이 목록만으로 특정 셰이더의 컴파일·링크 성공이나 GPU 시간을 판정할 수 없다. `drawCpu`의 호출 수에는 같은 요청이 포함될 수 있다.
