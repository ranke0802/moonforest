# 키보드 메뉴 진행 보강 — v4.19

방향키로 금색 테두리의 선택 항목을 이동하고 E 또는 J로 확정합니다. NPC 앞에서는 E로 대화를 연 뒤 다시 E를 누르면 수락합니다.

화면 오른쪽 위 `v4.19 · KEYBOARD`로 이 수정본인지 확인할 수 있습니다.

키보드 이벤트가 Update의 키 누름 검사에 잡히지 않아도 메뉴가 직접 처리하도록 보강했습니다. 같은 입력을 중복 처리하지 않으며, 확인 키를 누른 채로 다음 선택창까지 넘어가지 않습니다. 키 안내에 배경을 추가했습니다.

검증: 메뉴 16개(이벤트 직접 처리·길게 누름 포함), 실제 macOS 한글 입력 상태 E/E → 방향키/J 3개. 총 19개 통과, 런타임 오류 0. C# 및 셰이더 오류 없이 빌드 완료.

사용자가 올린 레벨업 화면과 동일한 실행 상태 자체는 재현하지 못했습니다. 위 검사는 별도 테스트 저장으로 실행했으며 기존 저장을 변경하지 않았습니다.
