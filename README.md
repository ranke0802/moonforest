# Moonforest · 달빛숲

Unity로 만드는 쿼터뷰 액션 RPG 프로토타입입니다. 위치·전사·궁수로 밤의 숲을 탐험하고 슬라임, 꿀벌, 은빛 달늑대와 전투합니다. 현재 소스 기준은 **v4.19**입니다.

## 실행

1. 저장소를 복제합니다: `git clone https://github.com/ranke0802/moonforest.git`
2. Unity Hub에서 복제한 폴더를 프로젝트로 추가합니다.
3. **Unity 6000.6.0f1**로 열고 첫 에셋 임포트가 끝날 때까지 기다립니다.
4. `Assets/Scenes/MoonlitForest.unity`를 열고 Play를 누릅니다.
5. 시작 화면에서 캐릭터와 이름을 선택합니다.

모델·텍스처·폰트·애니메이션·오디오와 `.meta` 파일을 포함합니다. Unity 캐시, 로컬 설정, 생성된 실행 앱은 저장소에서 제외합니다.

캐릭터 선택 화면에서는 왼쪽 미리보기를 좌클릭 드래그해 좌우·상하로 돌려볼 수 있습니다. 확대·축소는 고정이며 직업을 바꾸면 정면으로 초기화합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 카메라 기준 이동 |
| Shift | 달리기 |
| Space 단독 | 점프 |
| 전진·좌·우 이동 + Space | 구르기 |
| S + Space | 위치 순간이동 / 전사 방패 방어 / 궁수 백스텝 |
| J | 위치 자동 조준 공격 / 전사 연속 베기 / 궁수 자동 조준 연속 사격 |
| 마우스 좌클릭 | 위치 커서 방향 차징 공격 / 전사 연속 베기 / 궁수 차징 후 놓으면 발사 |
| U / I / K | 직업별 스킬 |
| 스킬 아이콘 클릭 → 우클릭 | 선택한 스킬을 지정한 위치·방향으로 시전 |
| Tab | 왼쪽 스킬 선택 |
| C / B / V | 상태창 / 가방 / 스킬창 |
| E | 가까운 NPC·사물과 상호작용 |
| Esc | 일시정지·소리 설정·저장·시작 화면 복귀 |
| Shift + 우클릭 드래그 / 휠 | 카메라 회전 / 확대·축소 |
| Z | 기본 카메라 복원 |
| 0 | 개발자 설정 |
| 1 | 숲 그림자 전환 |
| 2 | 한국어 → 영어 → 일본어 전환 |

위치의 에너지볼은 누른 시간에 따라 강해집니다. 궁수 좌클릭은 0.6초 차징을 완료한 뒤 버튼을 놓으면 발사합니다. 전사와 궁수 J는 길게 누르면 다음 일반공격으로 이어집니다. 운석과 화살비는 이동 또는 새 행동 입력으로 시전을 취소할 수 있습니다.

## 모험 진행

캠프의 루미에게 E로 의뢰를 받습니다. 지정된 적 4마리 → 두 오염 지점 정화 → 보스 앞 쉼터 → 은빛 달늑대 → 유물 선택 → 약초 수집/정예 꿀벌 의뢰로 이어집니다. 왼쪽 목표와 미니맵 금색 표식을 따라갑니다. 의뢰·정화·보상 수령을 저장하며 같은 보상을 두 번 받지 않습니다.

B 가방에서 유물을 한 개 장착합니다. 보스전 사망·재접속은 보스 앞 쉼터에서 재도전합니다. Esc의 캠프 귀환은 주변에 적이 없고 최근 5초간 피해를 받지 않은 상태에서 가능합니다. H/R 테스트 명령은 개발자 모드에서만 사용할 수 있습니다.

기본 시점은 pitch 29.3°, yaw 144.1°, 직교 크기 6.004입니다. Z로 복원할 수 있고 개발자 패널에서 새 기본값을 저장할 수 있습니다.

## 게임 구성

- 경험치·레벨업과 3가지 강화 선택지, 무기 장착/해제, 저장·불러오기.
- 직업별 공격·스킬·회피, 몬스터 넉백·빙결·속박·스턴 및 보스 공격 예고.
- 미니맵, 체력/마나 바, 피해 플로팅 텍스트와 `Critical` 표시.
- 시작·탐험·보스전 BGM, 효과음·환경음, 음량과 음소거 설정 저장.
- 60FPS 제한과 창 크기·카메라·언어 설정.

## 빌드 및 검증

Unity의 Build Profiles에서 macOS 빌드하거나 아래 프로젝트 빌드 함수를 사용합니다. 경로는 환경에 맞게 지정합니다.

```sh
"$UNITY_EDITOR" -batchmode -quit -projectPath "$PROJECT_PATH" \
  -executeMethod ForestMusicImport.Deliver \
  --v4-build-output "$OUTPUT_PATH/WitchMoonlitForest.app" \
  -logFile "$OUTPUT_PATH/build.log"
```

실행 앱에 `--audio-verify <결과 폴더>`를 전달하면 입력·효과음 및 기존 오디오 동작을 검증합니다. 테스트는 별도 저장 키를 사용합니다. v4.13에서 **86개 검증 통과, 실행 오류 0개, 빌드 오류·경고 0개**를 확인했습니다.

## 에셋 및 음원

사용자가 제공한 Meshy 모델·숲 배경과 프로젝트 제작 이미지·리깅·애니메이션을 사용합니다. 시작 테마 및 탐험·보스 편곡은 이 프로젝트용 MIDI로 제작했고 효과음은 Python으로 합성했습니다. 음원 생성 소스는 `Tools/Music`에 있습니다.

악기 음색은 S. Christian Collins의 **GeneralUser GS 2.0.3**입니다. [배포 라이선스](Tools/Music/GeneralUser-LICENSE.txt)를 함께 보관합니다. 폰트 라이선스는 해당 에셋 폴더에 포함합니다. 저장소 전체에 별도의 오픈소스 라이선스를 부여하지 않았으며, 개별 외부 에셋의 이용 조건은 각 원본의 조건을 따릅니다.

## v4.16 조작 및 의뢰 표시

루미 머리 위 `?`는 새 의뢰, `!`는 완료된 의뢰를 뜻합니다. 완료 후 루미와 이야기하면 다음 의뢰 `?`로 바뀝니다. 진행 중에는 표식을 숨기며, 모든 의뢰가 끝나면 완료 `!`를 유지합니다.

전사 기본공격은 J/좌클릭 모두 매 타격 시작 시 가장 가까운 생존 적을 향해 전진합니다. 벽 너머·다른 높이의 적을 제외하고 발밑에 대상 표식을 표시합니다. 대상이 없으면 현재 방향으로 공격합니다.
