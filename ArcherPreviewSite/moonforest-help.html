맵에 소품 놓고 옮기기

  1. 맵 꾸미기를 열고 맵 준비가 끝날 때까지 기다립니다.
  2. 종류에서 나무·바위·소품·풀을 고르고, 아래 목록에서 원하는 모양을 선택한 뒤 소품 놓기를 누릅니다.
  3. 화면에 놓인 소품을 직접 누르고 끌어 옮깁니다. 회전과 크기는 편집 창에서 바꿉니다.
  4. 대상이 잘 안 보이면 선택 소품 보기를 누릅니다. 화면 회전은 빈 곳을 끌어 회전하고, 화면 이동은 끌어 시점을 옮깁니다. 휠이나 ＋·−로 확대합니다.
  5. 게임에 적용을 누르면 바뀐 배치로 게임을 할 수 있습니다.

게임 중에는 대상 가까이 가서 주변 오브젝트 편집을 누르세요. 목록에서 기존 소품이나 내가 추가한 소품을 고르면 그 대상을 보여 주며 편집을 엽니다.

나무 4종·바위 2종·소품 3종·풀과 덤불 4종을 사용할 수 있습니다. 집·지형·퀘스트 물건과 동굴의 기존 소품은 충돌·진행 보호 때문에 편집이 제한됩니다. 기존 대상을 편집한 뒤 ‘원래대로’를 누르면 원본 배치로 복구합니다. 다른 지역은 위쪽 만들기 메뉴에서 엽니다.

배우와 물체로 컷씬 만들기

  1. 지역을 고르고 장면 열기를 누릅니다. 준비 중에는 가운데 화면에 진행 상황이 나옵니다.
  2. 종류에서 몬스터·나무·바위·소품·풀을 고른 뒤 아래 목록에서 대상을 선택합니다. 배우 추가 또는 물체 추가를 누르면 새 대상을 화면에 맞춰 보여 줍니다. 추가 중에는 버튼에 진행 상태가 표시됩니다.
  3. 화면의 배우나 물체를 직접 눌러 선택하고, 끌어서 옮깁니다. 선택 대상 보기로 다시 찾을 수 있습니다. 선택한 몬스터의 동작은 배우 조작에서 바꿉니다.
  4. 화면 회전이나 화면 이동을 골라 구도를 조정하고 시점 저장을 누릅니다. 움직이는 카메라는 구도를 바꾼 뒤 끝 시점 저장을 누릅니다. 재생으로 확인합니다.
  5. 게임에 저장을 누른 뒤 게임에서 열기를 누릅니다. 게임 화면에서 재생 버튼을 누르면 저장한 장면을 볼 수 있습니다.

화면 이동 모드에서는 대상을 잡지 않고 화면을 움직입니다. 대상 편집은 화면 회전 모드로 돌아와 진행하세요. 가운데 화면을 누른 뒤 W A S D로 이동, Q / E로 아래/위 이동, 휠로 확대할 수 있습니다. 숫자를 직접 다루는 기능은 고급 설정에 모아 두었습니다.
