# 현재 웹 게임 음향

기준: 2026-10-30. 기존 `mix-combat-audio.py`의 녹음 Foley 편집 + Scott Buckley 오케스트라 루프 제작 방식을 이어갑니다. 이전 Unity `Tools/Music`의 MIDI/합성 음향과 구별합니다. 신규 AI 생성, Runway, 유료 생성 API는 사용하지 않습니다.

현재 BGM 5개(지역 3 / 일반 전투 / 보스), 환경음 3개, 효과음 이름 51개입니다. 기존 효과음 31개와 보스 BGM의 콘텐츠 해시를 보존했습니다. 추가 편집 27개는 BGM 4 / 환경음 3 / 효과음 20개입니다. 패링 원본은 보존하지만 현재 방어 접촉은 BLOCK 효과음에 통합되어 별도로 재생하지 않습니다. 미구현 대화·문 열기·상자·함정 상호작용은 임의로 발동시키지 않습니다.

## 편집 및 갱신

원본은 저장소 밖에 보관하고 읽기 전용으로 사용합니다. 출처·이용 조건·변경 내역은 `scripts/world-audio-sources.json`과 `public/AUDIO_CREDITS.txt`를 같이 갱신합니다. Scott Buckley 음악은 CC-BY 4.0이며 작곡가·사이트·라이선스·수정 내역을 배포물에 유지합니다. 기존 Will Leamon 효과음의 OGA-BY 3.0 표기도 유지합니다.

```sh
# 원본을 실제로 수정할 때만 수행. 기존 combat script를 덮어 실행하지 않습니다.
python scripts/mix-world-audio.py <새_출처_폴더> <기존_Foley_폴더> <sb_thesummoning.mp3>
# 저장된 편집 결과만 패킹합니다. 다운로드/AI 생성/모델 변환 없음.
node scripts/prepare-audio.mjs
node scripts/report-world-audio.mjs <선택적인_휴대용_HTML_보고서_폴더>
node --test tests/audio.test.js tests/world-audio.test.js
```

새 음향 연결은 `src/game-audio.js`, `src/audio-beds.js`, `src/action-audio.js`, `main.js`의 음향 이벤트에 한정합니다. 전투 판정·입력 타이밍은 변경하지 않습니다. BGM은 맵 준비 완료 후 시작하며, 일반 전투보다 보스 전투가 우선합니다. 마지막 적이 죽으면 2.5초 후 지역 음악으로 복귀합니다. 설정창/숨김 탭에서는 AudioContext를 정지하며, 최초 사용자 제스처 전에는 재생·다운로드를 시작하지 않습니다.

## 용량 및 수명 제한

- BGM·환경음은 요청된 상황만 다운로드/디코딩합니다. 게임 로딩 완료를 음악 다운로드로 지연시키지 않습니다.
- 효과음은 최대 3건 병렬 준비, 같은 URL은 한 번만 디코딩합니다. 동시 효과음 12개, 거리 18 m 제한과 우선순위를 유지합니다.
- 음악/환경음 준비는 1건씩 처리합니다. 캐시에는 최근 BGM 2개와 모노 환경음 2개만 남습니다. 현재 파일 기준 PCM 상한 약 43.95 MiB이며 효과음 메모리는 별도입니다. 재생 중인 이전 버퍼와 캐시는 같은 객체를 참조합니다.
- 전환 중 오래된 fade voice는 다음 디코딩 전에 해제합니다. 음악 2 + 환경음 2 재생 소스가 최대입니다. `stopAll`은 즉시 소스를 끊고, `dispose`는 버퍼 캐시도 비웁니다.
- 오래된 비동기 결과가 새 맵 음악을 덮어쓰지 않습니다. 실패한 BGM은 같은 세션에서 자동 반복 요청하지 않습니다. 효과음은 계속 동작합니다.
- 모든 파일은 `audio.json`의 SHA-256 URL로 참조합니다. 변하지 않은 파일명·해시를 유지하고, 바뀐 음향만 새 파일로 배포합니다. 기존 서비스워커의 JSON 그래프·구버전 탭 보호·정리 정책을 그대로 이용합니다. 사용되지 않는 과거 버전을 manifest에 누적하지 않습니다.

## 배포 전 확인

전체 테스트 → `build:village` → `sync:village` → `stage-pages` 순서와 JSON 검증은 기존 README를 따릅니다. 모델·텍스처·LOD 패킹 명령은 음향 배포 때문에 실행하지 않습니다. `public/audio-credits.html`과 `AUDIO_CREDITS.txt`는 출처 포함 배포 파일입니다. `report-world-audio.mjs`로 HTML을 재현할 수 있습니다.

자동 검증 범위: 실제 파일 해시/디코딩/피크/라이선스 참조, 기존 음향 해시 유지, 36회 지역 왕복, BGM 우선순위/복귀, 동시 소스·캐시 한도, 실패/폐기/일시정지/비동기 경합. 브라우저 자동조작이나 S23 스피커 청취는 하지 않습니다. 최종 청감은 HTML의 자동 재생 없는 미리듣기와 실제 게임에서 사용자가 확인합니다.

2026-10-30 통합 검증: 최종 32 kHz AudioContext 옵션을 포함한 소스로 전체 478개 테스트를 다시 통과했고 최신 빌드를 생성했습니다. 기준 배포 `d27e4b2`의 콘텐츠 945개를 모두 유지하며, 신규 음향 27개(6,227,432바이트)만 추가합니다. 8K 플레이어·마을·숲·동굴과 바닥 manifest는 동일합니다. HTML은 효과음 변형까지 포함한 65개 미리듣기 항목(중복 제거 실제 파일 64개)을 제공하고 자동 재생·자동 다운로드를 하지 않습니다. 상세 증거는 `reports/world-audio-integration/verification.json`, 전체 로그는 같은 폴더의 `full-tests.log`입니다. 전송 계획의 0바이트 재방문은 캐시 시뮬레이션이며 실제 기기 통신·청감 측정은 아닙니다.
