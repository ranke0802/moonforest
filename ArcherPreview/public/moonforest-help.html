맵에 소품 놓기

  1. 맵 꾸미기를 열고 맵 준비가 끝날 때까지 기다립니다.
  2. 왼쪽에서 소품을 고른 뒤 소품 놓기를 누릅니다.
  3. 놓은 소품을 선택해 끌거나, 옮길 바닥을 찍습니다. 회전과 크기는 왼쪽 조작에서 바꿉니다.
  4. 게임에 적용을 누르면 바뀐 배치로 게임을 할 수 있습니다.

현재 추가할 수 있는 소품은 손수레·장작·상자/통 묶음입니다. 기존 집·지형·퀘스트 물건은 실수로 바뀌지 않도록 보호됩니다. 다른 지역은 오른쪽 위 만들기 메뉴에서 엽니다.

배우와 카메라로 컷씬 만들기

  1. 지역을 고르고 장면 열기를 누릅니다. 준비 중에는 가운데 화면에 진행 상황이 나옵니다.
  2. 배우를 고르고 배우 추가를 누릅니다. 동작을 고르면 그 배우에게 적용됩니다.
  3. 가운데 화면을 누르고 카메라를 움직입니다. 시작 시점 저장과 끝 시점 저장으로 구도를 정하고 재생합니다.
  4. 게임에 저장을 누른 뒤 게임에서 열기를 누릅니다. 게임 화면에서 재생 버튼을 누르면 저장한 장면을 볼 수 있습니다.

카메라 조작: 마우스 드래그로 회전, 휠로 확대/축소, 오른쪽 드래그로 시점 이동. 가운데 화면을 누른 뒤 W A S D로 이동, Q / E로 아래/위 이동, 방향키로 회전할 수 있습니다. 숫자를 직접 다루는 기능은 고급 설정에 모아 두었습니다.

저장한 작업 다시 열기

작업 저장으로 파일을 보관하고, 저장한 작업 열기에서 그 파일을 고르면 됩니다. 파일 안의 내용을 직접 수정할 필요가 없습니다.

브라우저 저장과 게임 적용은 현재 브라우저에 남습니다. 다른 기기나 브라우저에서는 작업 파일을 열어 주세요. 모든 사람의 게임에 공개하는 배포는 별도 작업입니다.
