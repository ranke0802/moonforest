맵 꾸미기와 컷씬 화면에서는 Ctrl을 누른 채 휠을 돌리면 미세하게 확대·축소하고, 맵 꾸미기의 ＋·− 버튼도 Ctrl과 함께 누르면 조금씩 움직입니다.

맵에 소품 놓고 옮기기

  1. 맵 꾸미기를 열고 맵 준비가 끝날 때까지 기다립니다.
  2. 종류에서 나무·바위·소품·풀을 고르고, 아래 목록에서 원하는 모양을 선택한 뒤 소품 놓기를 누릅니다.
  3. 화면에 놓인 소품을 직접 누르고 끌어 옮깁니다. 회전과 크기는 편집 창에서 바꿉니다.
  4. 대상이 잘 안 보이면 선택 소품 보기를 누릅니다. 화면 회전은 빈 곳을 끌어 회전하고, 화면 이동은 끌어 시점을 옮깁니다. 휠이나 ＋·−로 확대합니다.
  5. 게임에 적용을 누르면 바뀐 배치로 게임을 할 수 있습니다.

게임 중에는 대상 가까이 가서 주변 오브젝트 편집을 누르세요. 목록에서 기존 소품이나 내가 추가한 소품을 고르면 그 대상을 보여 주며 편집을 엽니다.

나무 4종·바위 2종·소품 3종·풀과 덤불 4종을 사용할 수 있습니다. 집·지형·퀘스트 물건과 동굴의 기존 소품은 충돌·진행 보호 때문에 편집이 제한됩니다. 기존 대상을 편집한 뒤 ‘원래대로’를 누르면 원본 배치로 복구합니다. 다른 지역은 위쪽 만들기 메뉴에서 엽니다.

컷씬 화면은 이렇게 나뉩니다

  • 왼쪽 목록: 맵을 열고 배우·물체를 추가합니다. 추가한 대상, 카메라 구간, 글과 소리를 여기서 고릅니다.
  • 가운데 미리보기: 대상을 직접 선택·이동하고 구도를 잡습니다. 위의 화면 회전 / 화면 이동으로 마우스 조작을 바꿉니다.
  • 오른쪽 선택 편집: 선택한 배우·카메라·글·소리의 설정만 보여 줍니다. 세부 수치는 펼쳐서 볼 수 있습니다.
  • 아래 타임라인: 재생 위치를 옮깁니다. 카메라·배우 동작·이동 경로·글·소리 줄의 항목을 누르면 그 시작 시각과 설정으로 이동합니다.
  • 위쪽 작업 버튼: 작업 파일을 열고 저장합니다. 되돌리기 / 다시 적용도 여기 있습니다.

넓은 화면에서는 양쪽 목록 안에서 각각 스크롤합니다. 화면이 좁으면 미리보기가 먼저 나오고 목록과 설정이 아래에 놓입니다. 화면 높이가 낮으면 작업 공간 아래로 스크롤할 수 있습니다. 버튼이 한 줄에 다 보이지 않는 타임라인은 옆으로 스크롤하세요.

전체 길이·등장 시각·배경 바꾸기

  1. 아래 전체 길이 / 초를 바꾸고 길이 적용을 누릅니다. 기본 설정은 배우·글·소리·카메라의 시간을 함께 비율로 늘리거나 줄입니다.
  2. 중간 시각에 배우를 추가하면 그 시각부터 등장합니다. 오른쪽의 등장 / 초, 퇴장 / 초, 등장하는 배경으로 바꿀 수 있습니다.
  3. 배경을 바꿀 시각으로 이동하고, 왼쪽 배경 맵 전환에서 맵과 연결 방식을 고른 뒤 현재 시각에 배경 저장을 누릅니다. 목록의 시각을 누르면 그 배경으로 이동합니다.

새 배경을 준비하는 동안은 재생 시계가 기다립니다. 뒤쪽을 잘라내는 길이 변경은 나중 작업을 지울 수 있으니 비율 조절을 먼저 사용하세요. 잘못 바꾸면 위쪽 되돌리기로 복구합니다.

컷씬 1 · 배우를 실제로 이동시키기

  1. 지역을 고르고 장면 열기를 누릅니다. 이어서 종류·목록에서 배우를 골라 배우 추가를 누릅니다. 프로젝트에 있는 배우·나무·건물·배경 소품을 고를 수 있습니다.
  2. 아래 처음을 누르고 배우를 시작 위치에 놓습니다. 시작 위치 기록 (0초)를 누릅니다.
  3. 아래 현재 초에 2를 입력합니다. 화면 회전 모드에서 배우를 끌어 다음 위치에 놓고 현재 위치에 경로점 저장을 누릅니다.
  4. 현재 초를 4로 바꾸고 다른 위치로 옮겨 같은 버튼을 누릅니다. 지점 목록의 이 지점 보기로 확인하고, 필요하면 시각을 고칩니다.
  5. 이동 연결에서 연결 속도를 고릅니다. 이동 방향 바라보기를 켜면 경로 방향으로 몸을 돌립니다. 회전과 크기는 배우 조작 버튼으로 바꿉니다.
  6. 0%·25%·50%·75%·100%를 눌러 중간 위치를 확인합니다. 화면에 경로 표시로 경로선을 켜고 끌 수 있습니다.

오른쪽 선택 편집의 배우에서 기본 동작을 고르세요. 중간에 다른 동작을 하려면 원하는 시각으로 간 뒤 현재 시각에 동작 추가를 누르고, 배우 동작 순서에서 동작·시작·끝·반복을 정합니다.

맵에 이미 있는 물체는 기존 물체 목록 보기에서 고르거나 화면에서 누른 뒤 기존 물체 편집에 추가를 누르세요. 그 뒤 이동 경로·방향·크기를 편집합니다. 컷씬용 편집이며 일반 맵 배치를 영구 변경하지 않습니다.

이동 경로와 몸의 동작은 함께 재생됩니다. 배우별로 따로 설정할 수 있습니다. 경로는 지정한 지점을 따라가는 연출이므로 지형과 물체를 보며 지점을 배치하세요.

컷씬 2 · 원하는 시각에 카메라 저장하기

  1. 아래 현재 초나 재생 막대로 저장할 시각을 고릅니다.
  2. 미리보기 위의 화면 회전에서 빈 곳을 끌어 회전합니다. 화면 이동은 끌어 시점을 옮깁니다. 휠은 확대·축소, Ctrl + 휠은 미세 확대·축소입니다.
  3. 원하는 구도가 되면 영상 오른쪽 아래의 큰 버튼 현재 …초에 시점 저장을 누릅니다. 시작은 0초, 마지막은 끝 시각에서 저장하세요. 중간에도 같은 방법으로 시점을 넣습니다.
  4. 왼쪽 카메라 구간을 고른 뒤 오른쪽 카메라에서 다음 구도까지 부드럽게 연결·일정 속도·바로 전환을 정합니다. 선택 배우 따라보기를 켜면 시선이 그 배우를 따라갑니다.

시작 시점 저장 / 중간 시점 저장 / 끝 시점 저장 / 구간 추가도 영상 오른쪽 아래에 있습니다. 좁은 화면에서는 이 버튼들이 영상 바로 아래에 표시됩니다.

시점 저장은 현재 작업 안에 카메라 구도를 기록합니다. 작업 전체를 파일로 보관하려면 위쪽 작업 저장을 누르세요. 둘은 다른 버튼입니다.

위쪽의 되돌리기로 최근 작업 5회까지 되돌리고, 다시 적용으로 5회까지 복구합니다. 숫자는 남은 횟수입니다. 되돌린 뒤 새로 편집하면 다시 적용할 기록은 지워집니다.

컷씬 3 · 몬스터 설명 글·자막·소리 넣기

  1. 왼쪽 목록에서 가운데 설명 글을 누릅니다. 추가한 글을 고르면 오른쪽에 문구와 시간 설정이 나옵니다.
  2. 문구에 몬스터 이름과 설명을 입력하고 시작·끝 시각을 정합니다. 줄바꿈도 사용할 수 있습니다.
  3. 아래에 표시할 대사는 아래 자막, 소리는 효과음을 눌러 추가하고 표시 시각·음량을 정합니다.
  4. 일시정지한 뒤 영상에 보이는 글을 직접 끌어 원하는 위치에 놓습니다. 아래 자막과 가운데 설명 글을 각각 옮길 수 있습니다.

가로 / %와 세로 / %에 위치를 입력해도 됩니다. 아래 기본 위치나 가운데 기본 위치를 누르면 기본 배치로 돌아갑니다. 잘못 바꿨으면 위쪽의 되돌리기를 누르세요.

컷씬 4 · 재생하고 보관하기

  1. 처음 → 재생을 누릅니다. 재생이 끝나도 제작 화면과 마지막 장면이 유지됩니다.
  2. 일시정지하거나 원하는 시각으로 이동해 다시 수정합니다. 반복을 켜면 연속 재생합니다.
  3. 작업 저장으로 편집용 파일을 내려받습니다. 저장한 작업 열기에서 이 파일을 다시 고를 수 있습니다.
  4. 게임에서 확인할 때만 게임에 저장 → 게임에서 열기를 누릅니다. 게임 화면의 재생 버튼으로 저장한 컷씬을 봅니다.

브라우저 저장은 같은 브라우저에서 이어집니다. 다른 기기에서는 작업 파일을 열어 주세요. 영상 파일 출력은 후속 기능입니다.

카메라 움직임과 글 효과

카메라 구간을 선택하고 오른쪽 카메라 움직임 만들기에서 다가가기·멀어지기·좌우 이동·위아래 이동·돌아보기를 고른 뒤 선택 구간에 움직임 적용을 누릅니다. 거리와 각도를 조절하고, 다음 구도까지에서 천천히 출발하거나 멈추는 연결을 고를 수 있습니다.

글을 선택하면 나타나기 / 사라지기에서 서서히 표시·이동·크기 변화·글자 하나씩 표시를 고를 수 있습니다. 오른쪽 화면 효과 탭은 장면 전체의 처음 밝아지기와 마지막 어두워지기를 정합니다.

배경 음악과 소리 파일

왼쪽 배경 음악을 눌러 기존 음악을 고르거나 효과음으로 짧은 소리를 추가합니다. 오른쪽에서 시작·끝·음량·반복·원본 시작 위치·서서히 켜고 끄는 시간을 정합니다. 브라우저가 소리를 막으면 미리보기 오른쪽 위의 소리 켜기를 한 번 누르세요.

소리 파일 추가로 내 음원을 고르면 재생 시간을 확인해 작업에 추가합니다. 파일은 최대 8개, 각각 16MiB, 합계 64MiB까지입니다. 가져온 음원이 있으면 작업 저장에 음원도 함께 포함되므로 다른 기기에서 그 작업 파일을 열어 이어서 편집할 수 있습니다.

저장한 작업 다시 열기

작업 저장으로 파일을 보관하고, 저장한 작업 열기에서 그 파일을 고르면 됩니다. 음원을 포함한 작업도 같은 버튼으로 엽니다. 파일 안의 내용을 직접 수정할 필요가 없습니다.

브라우저 저장과 게임 적용은 현재 브라우저에 남습니다. 다른 기기나 브라우저에서는 작업 파일을 열어 주세요. 기존 맵 물체 참조는 해당 배경을 열 때 실제 대상을 확인합니다. 모든 사람의 게임에 공개하는 배포는 별도 작업입니다.
