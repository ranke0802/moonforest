마지막 마을 표본이 약 60FPS여도 이전 구간의 하락이나 발열이 해결됐다는 의미는 아닙니다. 기기의 GPU 시간과 온도는 이번 로그에 없습니다.

플레이어 8K · 배경 최대 4K · LOD·표시 거리 · 전투·입력·판정 유지

로그에서 확인한 문제

  • 비탄의 마녀 변신 준비 중 장면 CPU 최대 약 148ms. 사망 시 약 199ms, 약 5.6초 뒤 사라지는 과정에서 약 134ms.
  • 대평원 426.8~427.6초에 CPU 45~126.5ms가 연속 기록됐습니다. 마지막 126.5ms 중 장면 처리는 11ms여서 장면 렌더링만 원인이라고 단정할 수 없습니다.
  • GPU 측정 미지원. CPU 장면 처리에는 여러 관찰자 작업과 드라이버 제출이 포함됩니다. GPU 실행 시간이나 기기 온도와 같지 않습니다.
  • 네 번의 로딩은 네트워크 다운로드가 0B여도 4.35~7.26초입니다. 캐시·모델 처리와 워커 초기화 경로를 조사했습니다.

이번 반영

  • 대평원·숲·동굴에서 색상 속성 유무가 다른 풍경의 외곽선 효과를 번갈아 다시 준비하던 작업 제거. 마을은 기존 반복 0 유지.
  • 캐릭터 외곽선에서 엔진이 이미 연결한 모프 데이터를 다시 연결하던 중복 제거(2회→1회). 뼈대별 연결과 외곽선 품질은 유지.
  • 같은 압축 geometry bin을 사용하는 텍스처 단계·glTF 변형은 동일 디코딩 결과를 재사용. 로더별 독립 복사와 8MiB 상한 유지. 초기 7회 계획의 decode miss는 701→697로, 최초 로딩 절감 폭은 작음.
  • 진단 보강: 지속 40FPS도 목표 프레임 미달로 집계하고 CPU 평균·p95, 풍경 갱신/HUD/활성 메시/그리기 제출 시간을 기록. 진단을 끄면 추가 계측 중단.

풍경 외곽선: 실제 에셋으로 재현

색상 속성이 있는 모델과 없는 모델이 같은 외곽선 재질을 번갈아 사용하면 준비된 효과를 다시 조회했습니다. 속성별 재질을 분리해 이 반복을 제거했습니다. 새 GPU 셰이더를 매번 컴파일했다는 뜻은 아닙니다.

  • 실제 배포 모델로 네 맵 외곽선 draw 횟수·색·굵기·안개·LOD·정리 경계 검사. 관련 50개 통과.

  • 브라우저 자동조작 없음. 실제 폰의 발열 감소·60FPS 안정 유지·보스 사망 지연 해소는 미검증.

남은 확인 범위

실제 폰에서 장시간 플레이한 뒤 60FPS 유지율과 발열 변화는 다시 확인해야 합니다. 진단에 목표 프레임 미달 횟수, CPU 평균·p95, 풍경 갱신·HUD·장면 세부 처리 시간을 추가했습니다. GPU 미지원 값을 0으로 표시하거나 CPU 수치로 대신 계산하지 않습니다.

최근 지연 목록은 느린 프레임을 선택한 기록이므로 전체 세션 평균이 아닙니다. 프레임 간격과 현재 CPU 작업 시간은 측정 구간이 달라 더하지 않습니다. 반복 처리 감소는 확인했지만 실제 온도 하락·완전한 60FPS 보장은 미검증입니다.
