MoonForest 0.1ver — 실제 컷씬 제작 기능·적용 순서
작성: 2026-11-04 / Asia/Seoul
기준 배포: bb48047ce021e6b25b73cbb8eb126981b70d472b

목표
코드·JSON·명령어 입력 없이 배우를 추가하고 이동 경로·동작·카메라·자막·효과음을 편집해 저장한다.
제작 미리보기는 끝나도 마지막 장면과 제작 상태를 유지한다. 게임에서 확인은 별도 명시적 버튼으로만 이동한다.

적용할 필수 기능
1. 제작 전용 재생 — 마지막 프레임 유지, 처음/끝 이동, 일시정지/재개, 반복, 재생 시점 표시.
2. 배우 경로 — 시작 위치 기록, 시각 선택, 대상 드래그/버튼 이동, 경로점 저장. 여러 배우의 독립 경로.
3. 경로 점검 — 화면 경로선/지점, 시각·위치 목록, 지점 이동/시간 수정/삭제, 0/25/50/75/100% 구간 체크.
4. 배우 방향/크기 — 직관적 회전 버튼, 크기 조절, 이동 방향 바라보기 선택.
5. 동작 순서 — 배우별 동작 목록, 시작/종료 초, 반복과 자연스러운 연결 수치. 경로 이동과 함께 재생.
6. 카메라 — 시작/중간/끝 구도 저장, 원하는 시각에 중간 컷 삽입, 여러 컷의 연속 연결/즉시 전환 선택, 샷 추가·복제·삭제·순서·길이, 선택 배우 따라보기.
7. 편집 마무리 — 실행 취소/다시 실행, 배우 복제/삭제, 아래 자막 또는 화면 가운데 몬스터 이름/설명 글, 문구·노출시간, 효과음 선택·시각·음량.
8. 저장 — 파일 저장·재열기·임시 저장, 편집 대기 중인 변경 반영 후 저장, 명시적 게임 확인.

구현 단계
A. 제작 종료 수명주기와 기본 재생 조작을 먼저 고친다.
B. 기존 공통 transform 트랙을 이용해 GUI 경로 편집·시각화·방향·타임라인을 연결한다.
C. 동작·카메라·자막/효과음·배우 관리의 기존 고급 기능을 이해할 수 있는 제작 흐름으로 통합한다.
D. 중립적인 기존 배우로 경로 작성→중간 좌표 점검→동작→여러 샷→재생 종료→수정→저장→재열기→게임 확인을 검증한다.
E. 통합 회귀·배포 파일 검사 후 기존 GitHub Pages에 MoonForest 0.1ver로 배포한다.

후속 후보(이번 적용 완료로 주장하지 않음)
- MP4/WebM 등 영상 파일 출력, 음성/립싱크, 조명·색보정·전환 효과, 곡선 손잡이 편집.
- 자동 장애물 회피나 보행 IK. 현재 경로는 사용자가 지정하는 연출 경로이며 게임 AI 이동 명령과 다르다.

보존·검증 범위
- 기본 30/선택 60FPS, 8K 플레이어/최대4K 배경, 기존 LOD/외곽선/카툰/내부선/240% 풍경거리 유지.
- 곰 컷씬 샘플은 가져오지 않는다. 신규 유료 에셋·API를 사용하지 않는다.
- 브라우저 자동조작 금지 유지. Node·실제 DOM 입력 전달·NullEngine·배포 HTTP 파일로 검사한다.
- 실브라우저 픽셀/OS 캡처·GPU·실기기 FPS/발열은 미확인으로 기록한다.
- 기존 dirty 파일을 보존하고, 진행은 work-state.json 및 단계별 보고서에 남긴다.
